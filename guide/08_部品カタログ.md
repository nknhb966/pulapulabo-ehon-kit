# 08 部品カタログ

このキットで使える部品の一覧です。絵本を頼むときに「使いたい部品」として名前を挙げると、その部品を使って作ります。何も挙げなければ、お話に合うものが選ばれます。

書き方のくわしいことは、右のはしの番号の説明書を見てください（**02** = [02 新しい絵本を作る](02_新しい絵本を作る.md)、**03** = [03 絵を用意する](03_絵を用意する.md)、**04** = [04 文章と読み上げ](04_文章と読み上げ.md)、**05** = [05 しかけ](05_しかけ.md)、**10** = [10 ぬりえ](10_ぬりえ.md)、**90** = [90 開発者向け](90_開発者向け.md)）。

## 頼むときの書き方の例

```
・使いたい部品：じゅんばんに タッチ（ほしを 1から 5まで）、そだてる（たねが はなに なる）、さいごは 大フィナーレ
・使いたい部品：ゆきが ふる、たき火の音、さいごは ネコが おうちへ 歩いて帰って まどに 明かりが つく
・使いたい部品：1ページめで かぎを みつけて、3ページめの ドアを あける（もちもの）。英語と ポルトガル語でも 読めるように
・使いたい部品：1ページめで おさいふを もって、3ページめの 金魚すくいで ポイを もらう（もっていなくても 手で すくえる）。つかまえた数が 4ページめの 金魚ばちに 出る
・読む子の年れい：3さい
```
