# 07 困ったとき

パソコンで作るときに よくあるトラブルです。見るとき・公開するときの そのほかのトラブルは、[06 公開と印刷 の「8. うまくいかないとき」](06_公開と印刷.md) にあります。

## 作るとき

**`npm` が見つからない（'npm' は認識されていません など）**
Node.js が入っていないか、入れたあとに VS Code を開き直していません。Node.js を入れて、VS Code を一度閉じて開き直してください。

**`npm install` で エラーになる**
VS Code で開いているのが キットのフォルダ（`pulapulabo-ehon-maker` など、`package.json` がある場所）か確かめてください。ターミナルの左に出ている場所の最後が そのフォルダ名になっていれば OK です。

**`npm run check` で ❌ が出る**
出てきた文のとおりに直します。ファイル名とどこが悪いかが書いてあります。よくあるのは：

- JSON の書きまちがい（`,` が多い・足りない、`"` のとじ忘れ）… VS Code の赤い波線のところを見てください
- 絵のファイル名と page.json の id がちがう（大文字・小文字もちがいとして扱われます）
- 絵が 4:3 でない … ページ全体の大きさで書き出し直します（切り抜かれていないか確かめる）
- `cat.png` と `cat.svg` の両方がある … どちらか1つにします
- SVG が外の画像ファイルを読みこんでいる … 画像を埋め込むか、その絵は PNG にします

**とても時間がかかる**
はじめてのとき、ページの絵や文章を変えたときは、認識データを作るので時間がかかります。変えていなければ、次からは速くなります。

**`npm run put-png` で ❌ が出る**
描いた絵を入れかえるときのトラブルです。[09 自分の絵に描きかえる の「うまくいかないとき」](09_自分の絵に描きかえる.md#うまくいかないとき) を見てください。ファイル名・大きさ（4:3）・まわりが透明か、の3つが よくある原因です。

**SVG の絵の文字が、ブラウザで見たときと違う**
作るときは、SVG の中の文字はすべて Zen Maru Gothic で描かれます。ほかの書体にしたいときは、文字をアウトライン化（図形に）してください。

## パソコンで見るとき

**preview.html をダブルクリックしても、何も出ない・まっ白**
少し待ってみてください（ファイルが大きいので数秒かかります）。古いブラウザでは動かないことがあります。Chrome・Edge・Safari の新しいものを使ってください。

**パソコンでカメラが動かない**
- `npm run serve` をして、http://localhost:8080/ で開いていますか？ `index.html` をダブルクリックで開いたときは、カメラが使えません
- `npm run serve` のページは、そのパソコンのブラウザでだけカメラが使えます。同じ Wi-Fi のスマホから開いても使えないので、スマホでは公開 URL で試してください
