# 10 ぬりえ（タブレットで いろを ぬる）

SVG で描いた絵本には、**ぬりえ** が ついています。子どもが タブレット（スマホ・パソコンでも）で 絵に いろを ぬると、その いろの まま AR の 絵が 立ちあがって 動きます。ワークショップにも 使えます。

## できること

- 絵が **線だけの ぬりえ** になります。いろを えらんで、ぬりたい ところを **タップ** すると、線で かこまれた ところが その いろに なります（はみ出しません。小さい子でも ぬれます）
- しっぽ・しま など、太い線で 描いた ところも ぬれます
- ＋・− か 2本の ゆびで 大きくして、こまかい ところも ぬれます
- 「ひとつ もどす」「けす（けしゴム）」「はじめから（この ページ／ぜんぶの ページ）」
- 紙に 印刷されない絵（あとで でてくる ほたる・かくれている ねこ など）も、下の「あとで でてくる え」から えらんで ぬれます
- ドアの むこうの 外の けしき（`"depth"` の 絵。しまった ドアの うしろに かくれている）も、下の「かくれている え」から えらんで ぬれます
- ぬった いろは、**その タブレットに 自動で 保存** されます（ページを とじても のこります）
- 「おわる」を おすと、プレビューと AR の 絵が ぬった いろに なります。まばたき・しゃべる・ばんざい など、ほかの 顔や ポーズの 絵にも 同じ いろが つきます
- **はいけいも ぬる：オン／オフ** … さいしょは **オフ**。はいけいは 見本の いろの まま、登場人物と 小物だけを ぬります（短い 時間の ワークショップ向き）。オンに すると はいけいも ぬれます
- **えほんの いろ：じぶんの いろ／みほんの いろ** … いつでも 見本の いろに もどせます（ぬった いろは 消えません）

ぬって いない ところは 白い まま（ぬりえと 同じ）です。1つも ぬって いない ページは、見本の いろで 動きます。

## 使いかた

1. 絵本の ページ（`https://（アカウント名）.github.io/<名前>/`、または `preview.html`）を タブレットで 開きます
2. はじめの 画面の **「ぬりえ」**（いちばん下の 小さな ボタン）を おします（ページの とちゅうに ぬりえの ボタンは ありません。よんでいる とちゅうに ぬるときは、左上の **「はじめ」** で はじめの 画面に もどります）
3. ぬったら **「おわる」** → 「はじめる」「カメラで はじめる」で、ぬった いろの 絵本が 動きます

- カメラで AR に するときは、いつもの 印刷した ページを うつします（紙の 絵は そのまま。AR の 絵が ぬった いろに なります）
- Claude の チャットの 中の プレビュー（アーティファクト）でも ぬれます。ただし 保存は その ブラウザだけです

## ワークショップでの ヒント

- 1人 1台が おすすめです。いろは その タブレットに 保存されるので、次の人の 前に「はじめから」→「ぜんぶの ページを けす」で 消します
- 「はいけいも ぬる」は さいしょ オフです（時間が みじかくても ぬりおわる）。じっくり ぬる ワークショップで さいしょから オンに したいときは、`book.json` に `"nurie": { "background": true }` を 書きます
- ぬった あとに カメラで 紙の ページを うつすと、自分の いろの 登場人物が 飛び出します。そこが いちばん もりあがります
- 家で つづけるときは、同じ アドレスを 家の タブレットで 開きます（いろは 端末ごとなので、家では はじめから ぬります）

## 作る人へ：ぬりえに 向く 絵

ぬりえは 絵本の SVG から 自動で できます。次のように 描くと、きれいな ぬりえに なります（AI に 作ってもらうときも、この 決まりで 描きます）。

- ぬる ところは **ぬり（fill）を もつ 形** に します。まわりに **線（stroke）** を つけると、白い ときも 形が 分かります（線の ない 形には うすい 線が 自動で つきます）
- いちばん 多く 使った 線の いろが「線の いろ」に なり、その いろで ぬった 小さな ところ（目・鼻）は ぬれません
- 目・口・目の ひかり（`class="eye"`・`class="mouth"`・`class="shine"`）は、描いた まま 残ります
- かげや ひかり（半とうめい: `opacity` が 1より 小さい 形）は、ぬりえでは 消えます
- しっぽ・ひも など 太い いろの 線（8 より 太い）は、線の いろを ぬれます。細い いろの 線（しま・ひげ）は、うすい 線に なって あとから ぬれます
- PNG で 描いた 絵は ぬりえに なりません（見本の いろの まま）

## 入れない とき

ぬりえを 入れない（ファイルを 小さく する）ときは、`book.json` に `"nurie": false` を 書きます。SVG の 絵が 1つも ない 絵本には、ぬりえの ボタンは 出ません。
