# 02 新しい絵本を作る

## 1. フォルダを作る

名前は半角の小文字・数字・`-` だけにします。

```
npm run new-book -- my-book
```

- 見本「ねこと おつきさま」（`books/sample-svg`、4ページ）が、まるごと `books/my-book` にコピーされます（ページ・はじめる画面の絵 `cast/`・もちものの絵 `items/`・英語とポルトガル語の訳 `lang/`・表紙の絵 `cover.svg` も）
- 題名は「あたらしい えほん」になり、作者名（`author`）と GitHub のアカウント名（`github`）は空になります。それ以外の設定は見本のままです
- 見本の絵は SVG です。SVG のまま描きかえても、お絵かきアプリで描いた PNG に置きかえても、混ぜてもかまいません（[03 絵を用意する](03_絵を用意する.md)）
- `npm run build` で作られる絵本が `my-book` に切りかわります（できあがりは `publish/my-book/`）

> **名前は、公開したときの URL にもなります**（`https://あなたの名前.github.io/my-book/`）。短くて、内容がわかる名前がおすすめです。

まずは何も変えずに `npm run build` をして、`publish/my-book/preview.html` で見本と同じものができることを確かめます。そのあと少しずつ書きかえていくのが、いちばん迷いません。

## 2. フォルダの中身

```
books/my-book/
  book.json              絵本全体の設定（題名・登場人物・声など）
  read.json              セリフの読み上げ方（なくても OK）
  cast/                  はじめる画面に出す登場人物の絵（cat.png や cat.svg。なくても OK。ごほうびスタンプにも使う）
  items/                 もちものの小さな絵（key.svg など。なくても OK：同じ id の飛び出す絵を使う）
  lang/                  ほかの言葉の訳（en.json・pt.json。npm run lang で作る）
  pages/
    p1/
      page.json          このページの文章・飛び出す絵の一覧・しかけ
      layers/            このページの絵（.png でも .svg でも）
        _background.png  紙に残る背景
        cat.png          飛び出す絵（1つずつ）
        moon.svg
        moon@awake.svg   さわったときに切りかわる絵
        ...
    p2/ ...
```

絵の描き方は [03 絵を用意する](03_絵を用意する.md)、文章は [04](04_文章と読み上げ.md)、しかけは [05](05_しかけ.md) にあります。

## 3. book.json の書き方

```json
{
  "title": "ねこと おつきさま",
  "subtitle": "AR えほん",
  "author": "越前市ぷらぷらぼ",
  "github": "nknhb966",
  "age": 5,
  "languages": ["ja", "en", "pt"],
  "pages": ["p1"],
  "cast": [
    { "id": "cat", "name": "ミミ", "look": "しろと オレンジの ねこ", "about": "おつきさまが だいすき",
      "color": "#f08a3c", "voice": { "pitch": 1.2, "rate": 1.0 }, "meow": { "pitch": 1.1, "length": 0.55 } },
    { "id": "moon", "intro": false, "name": "おつきさま", "color": "#e2a92a", "voice": { "pitch": 0.85, "rate": 0.85 } }
  ],
  "narrator": { "pitch": 1.0, "rate": 0.92 },
  "settings": { "readFirst": true, "voiceOn": false, "ending": true, "forAdults": true, "highlight": true },
  "textPanel": { "under": "#2b5a4a", "mark": "number" },
  "outline": { "color": "#fff3d9", "width": 6 },
  "print": { "cover": true, "colophon": true }
}
```

| 項目 | 意味 |
|---|---|
| `title` | 絵本の題名（はじめる画面・印刷 PDF・ブラウザのタブに出ます） |
| `subtitle` | 題名の下の小さな文 |
| `author` | 作者名（表紙・奥付・「おしまい」の画面・「おとなの かたへ」に出ます。なければ `""`） |
| `github` | 公開する GitHub のアカウント名。公開ページの URL（`https://<アカウント名>.github.io/<絵本の名前>/`）になり、表紙と奥付の QR コードに入ります。あとで書いて作り直しても OK |
| `url` | 公開ページの URL を自分で決めるとき（ふつうは書かない。`github` より先に使われる） |
| `date` | 奥付の発行日（書かないと、作った日） |
| `age` | 読む子の年れい（3・5・7）。[05 しかけ](05_しかけ.md) の「年れい」 |
| `languages` | 読める言葉。`["ja"]`（日本語だけ）、`["ja", "en", "pt"]`（英語・ポルトガル語も）。[04 文章と読み上げ](04_文章と読み上げ.md) の「いろいろな言葉」 |
| `items` | もちもの（ページをまたいで持っていくもの）`[{ "id": "key", "name": "かぎ" }]`。[05 しかけ](05_しかけ.md) の「もちもの」 |
| `adultNote` | 「おとなの かたへ」に足す ひとこと（なくても OK） |
| `pages` | ページの順番。`pages/` の中のフォルダ名を並べます |
| `cast` | 登場人物（しゃべるもの）。くわしくは下の表 |
| `narrator` | 文章を読む声。`pitch`（高さ）・`rate`（速さ）は 1 がふつう、0.5〜2 |
| `settings.readFirst` | `true` だと「おはなし → あそぶ」の2段階。`false` だとすぐ遊べる |
| `settings.voiceOn` | `true` だと、セリフの声が最初からオン |
| `settings.voice` | 読み上げの声。書かないと `"kid"`（子ども向けの かわいい声：女の人の声で、少し高く）。`"normal"` で ふつうの声 |
| `settings.ending` | `true` だと、ページをクリアするたびに ごほうびスタンプ、最後のページをクリアすると「おしまい」ボタンが出て、押すと「おしまい」の画面（スタンプの一覧、「はじめに もどる」「さいしょから よむ」のボタン、いちばん下に さく：作者名） |
| `settings.forAdults` | `true` だと、はじめる画面に「おとなの かたへ」（使いかた・安全・この絵本について） |
| `settings.highlight` | `true` だと、読み上げている行が、ページの文章の上で光る |
| `textPanel` | 文章の箱の見た目。`under`：箱のうしろの色、`mark`：右の印（`"number"` ページ番号／`"paw"` 肉球／`"none"` なし）、`fill`・`border`：箱の色、`size`：`"large"` で大きい文字（1ページ 3行まで） |
| `outline` | 飛び出す絵のふちどり。`color`：色、`width`：太さ、`"enabled": false` でふちどりなし |
| `hand` | 主人公の 手：タッチした ところに 出る 手のあと と、遊びで 道具が ないときに つかまえる手（`cat`・`dog`・`bear`・`rabbit`・`bird`・`human`、または `{ "kind": "cat", "color": "#…", "pad": "#…", "print": "#…" }`。`print` は 手のあとの 色）。書かないと 主人公（`cast` の 1人め）の 言葉から 自動で えらぶ（わからないときは check が 知らせる。[05 しかけ](05_しかけ.md) の「道具と手」） |
| `print` | 印刷 PDF：`"cover": true` で表紙、`"colophon": true` で奥付（最後の紙）を付ける（どちらも QR コード入り）。説明文を変えたいとき：`"caption"`・`"note"` |

> 見本（`books/sample-svg`）は、ここにある設定をすべて使っています。`npm run new-book` でコピーすると、`title` は「あたらしい えほん」、`author`・`github` は空になり、ほかは見本のままです（`languages` も `["ja", "en", "pt"]`）。英語・ポルトガル語がいらないときは `["ja"]` にします。
>
> 表紙（`cover.svg`）・もちものの絵（`items/`）・はじめる画面の絵（`cast/`）も見本のままコピーされます。見本の絵のままだと `npm run check` で「⚠️ 見本の絵のままです」と出るので、この絵本に合わせて描きかえます。

### cast（登場人物）の項目

| 項目 | 意味 |
|---|---|
| `id` | 絵の名前と同じにします（`cat` なら `layers/cat.png` の絵がしゃべる） |
| `name` / `look` / `about` | はじめる画面の紹介（名前・見た目・性格） |
| `intro` | `false` にすると、はじめる画面に出さない（しゃべるけど紹介しない役） |
| `color` | 吹き出しの色 |
| `mark` | 進み具合の丸の色、`frame`：紹介カードのふちの色（なくても OK） |
| `firework` | 花火の色（花火を使うとき） |
| `voice` | 声の高さ・速さ。差を大きくしすぎると不自然になるので、0.85〜1.3 くらいがおすすめ |
| `meow` | 鳴き声（音 `meow`）の高さと長さ |

はじめる画面の絵は `cast/<id>.png` か `cast/<id>.svg` に置きます（なければ文字だけ）。こちらは 4:3 でなくてかまいません。

## 4. ページを増やす・減らす

見本は4ページ（p1・p2・p3・p4）です。ページを足すときは：

```
npm run add-page
```

- 最後のページがコピーされて `pages/p4` ができ、`book.json` の `"pages"` の最後に足されます（`--from p1` で、コピーするページを選べます）
- `pages/p4/layers/` の絵と `pages/p4/page.json` を、そのページの場面に書きかえます

ページを減らすときは、`book.json` の `"pages"` からそのページの名前を消します（フォルダは消さなくても使われません）。ページの順番も `"pages"` の並びで決まります。

### 何ページもある絵本を作るときのコツ

- **背景はページごとに はっきり変えます。** カメラは印刷したページの絵のちがいで、どのページかを見分けます。同じ背景の使い回しは避けてください
- 登場人物は全ページで同じ見た目に。PNG なら同じ絵を使い、SVG なら1つのページで描いた絵をコピーして位置と大きさだけ変えます（見本の p1〜p3 がそうなっています）
- 遊び（`goal`）はページごとに変えると楽しくなります（見本は p1 さがす・p2 時間内に ぜんぶ タッチ・p3 なんども タッチ）
- お話がページをまたいでつながるように。最後のページは、クリアしたときのお祝い（`done`）で しめくくると、終わりがはっきりします
- クリアの前と後で、登場人物のセリフを変える（`after`）と、お話が進んだ感じが出ます。登場人物に笑顔の絵（`@happy`）を用意しておくと、クリアしたときに自動で笑顔になります
- 文章は どのページも 4行まで

## 5. 書いたら確かめる

```
npm run check
```

まちがいがあると ❌ で、どこをどう直せばよいかが出ます。⚠️ は「たぶん大丈夫だけど確かめて」という意味です。

## 6. ほかの絵本に切りかえる

```
npm run use                  ← 絵本の一覧（★ がいま作る絵本）
npm run use -- sample-svg    ← 切りかえ
```

## 表（Excel）で書く

book.json・page.json・read.json は、**Excel の表** でも書けます。動き・音・演出・遊び などは ▼ の一覧から えらべるので、名前を まちがえにくくなります。

```
npm run excel        ← out/<絵本の名前>_表.xlsx ができる（いまの book.json・page.json・read.json の中身）
```

1. `out/<絵本の名前>_表.xlsx` を Excel・LibreOffice・Google スプレッドシート（アップロードして開く）で開きます
2. シートを直します（「はじめに」の シートに 書きかたが あります）

   | シート | 中身 |
   |---|---|
   | 本 | 題名・作者名・年れい・ことば など（book.json） |
   | 登場人物・もちもの | book.json の `cast`・`items` |
   | ページ | ページの順番・場面の名前・背景のひな形・天気・環境音 |
   | 文章 | 各ページの文章と読み上げ（`story`） |
   | 絵 | 飛び出す絵の ならび（`pieces`。上ほど奥） |
   | さわる | さわったときの反応（`touch`） |
   | 遊び・クリア | ページの遊び（`goal`）と クリアしたとき（`done`） |
   | セリフの読み | read.json |

   - ○ は「する」、× は「しない」、いくつか書くときは「 / 」で区切ります（例：`catHello / catJoy`）
   - 表の列に ない 細かい設定は、いちばん右の「そのほか（JSON）」に JSON のまま 入っています。わからなければ そのままにします
3. 保存して（Google スプレッドシートなら Excel 形式で ダウンロードして `out/` に置き）、次を打ちます

```
npm run excel-in     ← 表のとおりに book.json・page.json・read.json を書きかえる
npm run check
npm run build
```

- 前の json は `out/<絵本の名前>_json_backup/` に しまわれます（もとに戻したいときは そこから コピー）
- 表の書きかたに まちがいがあると、どのシートの 何行めかが出て、json は 変わりません
- json を 直接 書きかえたあとに 表を作りなおすときは `npm run excel -- --new`（書きかけの表は 上書きされます）

## JSON を書くときの注意

- 文字は `"` でかこみます（`'` や `“ ”` ではなく、半角の `"`）
- 項目と項目のあいだは `,`（半角カンマ）。**最後の項目のうしろには付けない**
- `true` / `false` / 数字は `"` でかこまない
- 書きまちがいがあると、`npm run check` で どのファイルのどこかが出ます
