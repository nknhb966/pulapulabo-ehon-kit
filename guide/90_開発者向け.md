# 90 開発者向け

## 全体の流れ

```
books/<id>/                       system/tools/build.mjs
  book.json, read.json        ──┐   1. check（lib/check.mjs）
  cast/<castId>.png|svg         │   2. ページの絵を作る（lib/art.mjs）
  pages/pN/                     │        PNG/SVG を 1600×1200 と 3200×2400 にラスタライズ（lib/layers.mjs）
    page.json                   │        → sharp でふちどり・影、切り抜き、減色
    layers/*.png|svg            │   3. 認識データ .mind（lib/mind.mjs → vendor/mind-ar/mindar-node-compiler.mjs、.cache/mind にキャッシュ）
    script.js                   │   4. フォントのサブセット（subset-font）
system/engine/*.js            ──┤   5. esbuild で ehon/ の各ファイルにまとめる
                                │   6. 印刷 PDF（lib/pdf.mjs, pdf-lib）
                                └─→ publish/<id>/index.html, preview.html, ehon/, print/, THIRD_PARTY_LICENSES.txt
```

- 出力は短い `index.html`・`preview.html` と `ehon/` フォルダ。`ehon/` は、three.js（`window.THREE`）→ MindAR（`window.MindARThree`、index のみ）→ `licenses.js`・`pictures.js`（`window.EHON_PICTURES`）・`book.js`（`window.EHON_BOOK`）→ `engine.js`（`window.EhonEngine`、圧縮なし）の順に、ふつうの `<script>` で読みこむ。ES モジュールや fetch を使わないので、`preview.html` はファイルを直接開いても（file://）動く。認識データ `targets.mind` だけは MindAR が URL から読む（index は https のページで開く）。`targets.mind` は ページの順で、`"print": { "cover": true }` のときは 最後に 印刷する表紙（A4 横の紙ぜんぶ）が入る（`pictures.js` の `coverTarget`）
- 各ファイルには内容のハッシュを `?v=` で付けて読みこむ（上げ直したときに古いキャッシュと混ざらない）
- 絵は `pictures.js` の中にデータとして入れる（file:// で開いたページは、別の画像ファイルを WebGL のテクスチャに使えないため）
- ビルドの途中物は `.cache/`。`.cache/mind/<sha1>.mind` は認識データのキャッシュで、ターゲット画像が同じなら再利用します

## 奥行きと 重なり

- カードは 足もと（いちばん下の端。`pivot` が bottom のとき）を軸に 立ち上がるので、足もとの y が 前後の位置になる。きまりは 最大5列（`lib/layout.mjs` の `ROWS`。check の「1列に ならんでいます」も ここを使う）
- `parent` の ある カードは 親の 面に つく（ふつうは `pieces` の順に 0.0006 ずつ 手前、`behind` の カードは うしろ）。`"depth": N` の カードは 親の N px うしろに 親と 平行に 立つ（戸口・まどの むこうの 外の けしき）。親が かたむくと 床より 下に 入る ところは、紙（plate）が 深さで かくす。印刷・ぬりえ・下絵では `behind`／`depth` の 絵を 親の 下に かさねる（`art.mjs`・`nurie.js`・`shitae.mjs`）
- `open`：`pivot` left / right の カードを `rotation.y` で 回す。ふつうは 外へ（left は +、right は −）。同じ 親の `depth` の カードに ぶつからない 角度まで（`asin((depth−14)/はば)`、最大 1.3）。`"opens": "in"` は 手前へ ±1.45
- 吹き出し・マークの 位置は `pg.anchor(id)`：カードの 場所（pivot の中で still と body の 位置だけ。回転は 入れない）。`fx.js` の `follow` で なめらかに ついていく（0.25 より はなれたら すぐ）。マークは その人の 吹き出しが ある あいだ 出ない（`Labels.speaking`）。ほかの人の 吹き出しを よけて 横へ ずれることは しない（いつも 自分の 頭の 真上）。`done` では セリフを いう 人の mark を とばす
- `"if": { "found": id }`：`pg.gs.foundIds`（find で 見つけた item）。`holds(spec, pg)` に ページを わたす
- クリアの あとも つづく 演出：`goalDone` → `startLasting(pg, effect, trail)`（`done.keep !== false`）。毎フレーム `lastingTick`（`scene.js` の `LASTING`：`from` 秒から `rate`/秒 と `every` 秒ごとの `event`）。虹は `MOODS.rainbow(pg, keep)` が `pg._rainbow` を のこす。花火は `pg.firework(…, { quiet, scale })`。`reset()` で けす。ひかえめモードは 虹と 光の道だけ
- `need` / `if` の 絵：`setOpen(true)` の すぐ（`logic.opening` → `whenHide`）に かくす。出てくる 絵（hidden）は 0.9 秒あとの `open` で
- タッチの 手のあと：`handOf()` の kind（cat・dog・bear・rabbit・bird・human）で `fx.js` の `printTexture`。色は `book.json` の `hand.print`（なければ `pad`）
- `"faces"`（left / right / front）：`flyOff`・`leap`・`drift`・`tumble`・`trip` の `dir` の ないときの 向き（`presets.js` の `faceOf`）。left / right の 絵は `walk` で 歩く 向きに `flipX`
- 足もとの差が 6px 以内で、左右に重なる カード同士は、`pieces` の順に 4px ずつ 手前に ずらして立てる（`page.js` の `nudge`。同じ所に 立って ちらつかないように）
- 吹き出し・オノマトペ・気持ちのマークは、さわるたびに 新しい「層」になり（`Labels.touched()`）、`renderOrder` が 前の層より大きくなる（最後に さわった物の文字が 手前）。`pg.later` で あとから出るものは、予約したときの層のまま（`Labels.inLayer`）。同じ層の中は マーク < 文字 < 吹き出し

## layers の解決

- `layers/<name>.png` か `layers/<name>.svg`（両方あるとエラー）。`_background`、`<id>`、`<id>@<alt>`
- `_background` がなく page.json に `"background"` があれば `system/backgrounds/<名前>.svg`
- ビルドの最初に表情ツール（`lib/faces.mjs`）が、`class="eye"` のある SVG から `<id>@blink`・`@talk`・`@happy`（と page.json にある `@surprise`・`@sad`・`@sleep`）を、まだないものだけ `layers/` に書き出す。作った絵には `pulapulabo-faces:<元の絵のハッシュ>` のメモが入り、元の絵が変わると作り直す（メモのない絵は手描きとして残す）
- SVG は resvg でレンダリング（フォントは Zen Maru Gothic のみ、システムフォントは読まない）。外部画像の参照はエラー
- どちらも 4:3 ならピクセル数は自由（そろっていない PNG は警告のみ）
- `npm run png`・`svg` は layers の絵（と表紙・cast・items）を同じ名前で `out/<id>_png/`・`_svg/` に出す（png は SVG を resvg で 2400×1800 に、svg は SVG のまま。PNG はどちらもそのままコピー。`_下絵.png` は背景＋見えている飛び出す絵＋文章の箱、`_ガイド` は `lib/layout.mjs` の5列と文章の箱）。`npm run put-png` はその逆で、名前（`p1/cat.png`・`p1/cat.svg`・`p1_cat.png`・`cover.*`・`cast/`・`items/`）から置き場所を決め、400 px 幅に縮めて今の絵と比べ（どちらかの絵がある所だけ）、同じなら入れない。入れかえた前の絵は `books/<id>/old-pictures/` へ。新しくなった `<id>` が PNG か、class="eye"・"mouth" のない SVG なら、表情ツールが作った `<id>@*.svg` は消す
- `npm run excel` は book.json・page.json・read.json を シート（本・登場人物・もちもの・ページ・文章・絵・さわる・遊び・クリア・セリフの読み）にし、▼ の一覧（隠しシート「リスト」：エンジンの MOVES・効果音・EFFECTS・遊び・天気・環境音、その絵本の script.js の moves、cast・pieces・items の id）を付ける。列にない項目は「そのほか（JSON）」に入れて往復で なくさない。`excel-in` は表から json を作りなおす（前の json は `out/<id>_json_backup/`）

## script.js（そのページだけの特別なしかけ）

ページのフォルダに `script.js` を置くと、page.json と合わせて使われます。

**まず page.json で書けないか考えます。** さわったときの反応（touch・after・then・on・wait・lock）、遊び（find・gather・mash・order・choose・pop・grow・dressup・rub）とその相手ごとの反応、クリアの演出（done）は page.json で書けます。script.js は、それで書けない特別な動きだけに使います。

```js
import { seg, react } from 'pulapulabo-ehon';

export default {
  hint: 'ドアを 3かい ノックしてね',      // page.json に hint がなければ使われる
  progress: { label: 'ノック', total: 3 },
  init(pg) { pg.state = { knocks: 0 }; },
  update(pg, dt) { /* 毎フレーム */ },
  play(pg) { /* おはなしが終わって「あそぶ」になったとき */ },
  tap(id, pg, hit) {                         // true を返すと、page.json の touch は動かない
    if (id !== 'door') return false;
    const st = pg.state;
    st.knocks++; pg.sfx('konkon'); pg.ono('コンコン', 'door', '#8a5a3a'); pg.progress(st.knocks, 3);
    if (st.knocks === 3) { pg.spin('door', 'y', 0.25); pg.say('cat', 'あいた！'); pg.complete(); }
    return true;
  },
  narration(pg) {                            // 書かなければ page.json の story から作られる
    return pg.story.map((t) => seg('n', t));
  },
};
```

呼ばれる順番：`script.tap` → page.json の `goal` → `skyFireworks` → page.json の `touch`。

### そのページだけの動き（"moves"）

キットにない動きは `moves` に作ると、page.json の `move`（touch・then・遊びの反応・done・story の act）で名前で使えます。
**動きが何秒かかるかを返すと**、その間は もう一度さわっても反応しません（押せない時間）。

**主人公や、そのページで いちばん大事なもの**（さわってほしいもの）は、キットの動きを1つ使うだけだと 単調になりがちです。
その絵本だけの動きを ここで作り、キットの動き（`pg.hop`・`pg.spin` など）や `pg.later` を組み合わせて、**ためて → 大きく動いて → 気持ちが見える** ような 流れにします。

```js
export default {
  moves: {
    // ネコが よろこぶ：小さく はねて、くるんと回り、もう一度 大きく はねる（2.4 秒）
    catJoy(pg, id) {
      pg.hop(id, 0.04, 0.6);
      pg.later(600, () => pg.spin(id, 'y', 1, 1.2));
      pg.later(1600, () => pg.hop(id, 0.09, 0.8));
      return 2.4;
    },
    // おつきさまが ゆっくり しずんで、また のぼる（2.4 秒）
    moonDip(pg, id, hit, spec) {
      const c = pg.C(id), b = c.body, bs = pg.base(c);
      pg.tween(2.4, (t) => { const u = Math.sin(Math.PI * t); b.position.y = bs.y - u * 0.05; b.rotation.z = u * 0.15; },
        () => { b.position.y = bs.y; b.rotation.z = 0; });
      return 2.4;
    },
  },
};
```

```json
"cat":  { "move": "catJoy", "sound": "meow", "say": "やったー！", "then": { "delay": 1.0, "word": "くるりん" } },
"moon": { "move": "moonDip", "sound": "chime", "swap": "sleepy", "back": 2.4 }
```

- **はやさ：** 小さな子が目で追えるように、頼まれていなければ「ゆっくり〜ふつう」にします。目安：1回まわる 1.2秒くらい、1回はねる 0.7秒くらい、ひと続きの動き 2〜3秒。キットの動き（hop 0.7秒・spin 1.2秒）は「少し ゆっくり」です。はやい動き（0.5秒より短い回転など）は、頼まれたときだけ
- **つながった動き：** 動きの最後は、なめらかに もとの位置へ もどします（`easeInOut` や `Math.sin(Math.PI * t)` で 0 に もどす）。とちゅうで パッと もとの位置に もどしたり、1秒に 6回より こまかく ふるわせたり しません
- 動きは `(pg, id, hit, spec)` を受けとります。`spec` は page.json に書いた反応そのもの（`spec.dir`・`spec.power` など、自分で決めた項目も読めます）
- 動きは そのピースの `body` を動かします。もとの位置は `pg.base(c)`（x・y・z）。動き終わったら もとの位置に もどします
- 名前がキットの動き（hop など）と同じときは、そのページでは こちらが使われます
- 見る人に出る文字（セリフ・オノマトペ）は、できるだけ page.json の `say`・`word` に書きます（ほかの言葉に訳されるのは page.json の文字だけです）。script.js の中の文字は、page.json のどこかに同じ文字があれば訳されます

### script.js を書くときのきまり

- **押せない時間は `pg.busy` / `pg.isBusy` で作ります。** 自分でフラグ（`busy = true` など）を作らないでください。リセットやページの移動で止まったままになるのを防ぐためです
- 遊びを script.js で作ったときは、クリアしたら必ず `pg.complete()` を呼びます（クリアの合図と `after` の反応のため）。page.json に goal も script.js に `complete()` もないページは、`npm run check` が ⚠️ で知らせます
- page.json の反応を script.js から使うときは `react(pg, id, { move: 'hop', say: '…' }, hit)` を使えます（押せない時間の決まりも同じようにかかります。かけたくないときは5つめに `{ free: true }`。ただし セリフの ある 反応は、`free` でも 言い終わるまで 同じ絵からは 出ません。さわったのではない 反応（時間が たったら 出す など）は `{ free: true, auto: true }`）

`'pulapulabo-ehon'` から使えるもの：`BOOK`、`voice(id)`、`castColor(id)`、`fireworkColor(id)`、`markColor(id)`、`castIds()`、`isCast(id)`、`addHalo`、`blinkHalo`、`MOVES`、`EFFECTS`、`react(pg, id, spec, hit, opts)`、`easeOutBack`、`easeInOut`、`hasItem(id)`（もちものを持っているか）、`finale(pg)`（大フィナーレ。自分で作ったクリアの演出のあとに）、`seg(who, text, onstart, line)`（`line` は story の何行めか。読んでいる行が光る）。three.js は `import * as THREE from 'three'`。
