# 04 文章と読み上げ

## ページの文章（page.json の "story"）

```json
"story": [
  { "text": "ねこの ミミは やねの うえ。", "read": "猫のミミは、屋根の上。" },
  { "text": "「おつきさま、こんばんは」", "read": "お月さま、こんばんは。", "act": "cat:hop" },
  "おつきさまは にっこり わらって いいました。"
]
```

- 1行が、文章の箱の1行になります。**4行まで**が読みやすい大きさです（長いと文字が小さくなります）
- 子ども向けに、ひらがなと単語ごとのスペースで書くのがおすすめです
- **地の文（「」の セリフで ない 文）は、おわりかたを まぜます：**

  | おわりかた | 例 |
  |---|---|
  | 体言止め（名前で おわる） | `きょうは はなびたいかい。` `ミミは おおよろこび。` |
  | です・ます | `もりの なかで、みちが みっつに わかれています。` `いちろうは おおきな たいこを みつけて かけだしました。` |
  | 語りかけ | `せーの で、ちからを あわせよう。` `くらくて、みちが よく みえないね。` `あれれ？ おかあさんが いない！` |

  「〜した」「〜する」で おわる 地の文は「〜しました」「〜します」に します。です・ます は **1ページに 1つ くらい**（地の文の 半分まで）が めやすです（check が「〜した。」の 文と、です・ます の 多すぎを 知らせます）。ぜんぶ です・ます に すると 絵本らしさが なくなります。「」の セリフは 話す 人の ことばの まま です
- 文字だけでよい行は、`"…"` のように文字だけ書けば OK

| 項目 | 意味 |
|---|---|
| `text` | 紙に印刷される文 |
| `read` | 読み上げる原稿（下を参照） |
| `act` | その行を読むときに動かす絵。`"cat:hop"` は「cat が hop（はねる）」。動きの名前は [05 しかけ](05_しかけ.md) の move と同じ。`["cat:hop", "moon:wobble"]` のように複数も可 |

### ふりがな・文字の大きさ

漢字を使うときは、`{漢字|かんじ}` と書くと、印刷される文章で 漢字の上に ふりがな が付きます。

```json
{ "text": "ねこの ミミは {屋根|やね}の うえ。" }
```

- 画面の吹き出しや読み上げでは、ふりがな（かな）が使われます
- ふりがなのある行は、上に少し すきまが できるので、文字が少し小さくなります
- 文字を大きくしたいとき（3さい向けなど）は、`book.json` の `"textPanel"` に `"size": "large"` を書きます。1ページ 3行まで にします

### 読んでいる行が光る

`book.json` の `settings` に `"highlight": true` を書くと、読み上げている行が、ページの文章の上で光ります（紙に印刷した文章の上でも光ります）。

## 読み上げ用の原稿（read）

スマホの読み上げは、ひらがなとスペースの文をそのまま読むと、単語ごとに区切れたり、アクセントがおかしくなったりします。そこで、**画面の文とは別に、読み上げ用の原稿**を書けます。

- 漢字を使う（アクセントが自然になります）：「おつきさま」→「お月さま」
- スペースは入れない
- 息つぎしてほしいところに「、」
- 「」は入れない

`read` がない行は、スペースを取りのぞいて読みます。

### 読みまちがいを防ぐ

声は スマホに入っている読み上げ音声なので、漢字の読みを まちがえることがあります（iPhone・Android・機種で ちがいます）。

- 「間に合った」→「あいだにあった」、「今日は」→「こんにちは」のように、**読みが2つある漢字**は、原稿でも `{漢字|よみ}` と書くと、その言葉だけ かなで読みます

```json
"「まにあったね！」4ひきは にっこり。": "{間に合|まにあ}ったね！ 四匹は、にっこり。"
```

- `npm run check` が、まちがえやすい言葉（間に合う・今日は・一日・上手・下手・何人 など）を見つけて ⚠️ で知らせます
- **漢字に すると かえって 読みまちがえる 言葉**は、ひらがな（または `{漢字|よみ}`）で 書きます
  - のばす 言いかたの 呼びかけ：「お母さあん」→「おははさあん」と 読まれる → 「おかあさあん」
  - 1字だけの 漢字：「頭、キーン！」→「とう、キーン」と 読まれる → 「あたま、キーン！」
  - 〇〇屋：「金魚屋の おじさん」→「きんさかなや」と 読まれる → 「きんぎょやの おじさん」
  - くだけた 言いかた：「離れちゃだめよ」→「はなれちやだめよ」と 読まれる → 「はなれちゃ、だめよ」
  - 短い カタカナの 道具名：「このポイを」を アルファベットのように 読む 声が ある → 「このぽいを」
  - 家：「お家へ かえろう」→「おいえへ」と 読まれる → 「おうちへ かえろう」
  - ねこの ことば：「行きたいにゃ」→「行きたいにや」と 読まれる → 読み上げ原稿は カタカナで「行きたいニャ」「ニャーン」「ニャッ」（吹き出しの 文字は ひらがなの まま で OK）
- **ひらがなだけの文は、言葉の区切りが分からず 読みまちがえやすくなります。** 「よみちは」の「は」が「ハ」と読まれたり、「たまやー」が「たまゆや」と読まれたりします。読み上げ原稿は 漢字まじりにして（「夜道は」）、のばす音は 母音で書きます（「たまやあ」「いただきまあす」）。check で ⚠️ が出ます
- **公開する前に、実際のスマホで聞いて確かめます。** `preview.html#yomi`（公開したら `https://<アカウント名>.github.io/<絵本の名前>/preview.html#yomi`）を開くと「よみあげ チェック」になり、すべての文章とセリフが ▶ で聞けます。原稿（よみ）も一緒に出ます。読みかたが ちがう言葉は、原稿を直します
- iPhone と Android の両方で聞けると安心です

## セリフ（吹き出し）

さわったときのセリフは `page.json` の `"touch"` や `"goal"` に書きます（[05 しかけ](05_しかけ.md)）。

いくつかの絵を つづけて さわって、吹き出しや オノマトペの文字が 重なったときは、**最後に さわった物の方が 手前に出ます**（キットが自動でします。少しあとに つづけて出る文字（`then`）も、さわった順のまま）。重ならないように 書く必要は ありません。

セリフの読み上げ方は、絵本のフォルダの **read.json** に「画面の文」：「読み上げ」の組で書きます。**セリフは すべて書きます**（遊びの ことば・道具を もらうときの セリフ・done の セリフ も）。`{名前}` の入った セリフも、そのまま `{hotaru}匹の ほたる` のように書けます。

```json
{
  "おつきさま、こんばんは！": "お月さま、こんばんは！",
  "みんな どこに いるのかな？": "みんな、どこにいるのかな？"
}
```

### えらんだものの名前を入れる

「えらぶ」遊びで えらんだもの（[05 しかけ](05_しかけ.md) の「えらんだ方で変わる」）は、セリフに `{名前}` と書くと入ります。

```json
"say": "{gift}、ありがとう！"
```

えらんだのが ケーキなら「ケーキ、ありがとう！」になります。印刷される文章（story）には使えません。

## いろいろな言葉（英語・ポルトガル語）

`book.json` に `"languages": ["ja", "en", "pt"]` と書くと、**もじ（画面の 文字）** と **こえ（読み上げ・セリフの 声）** の 言葉を、それぞれ べつべつに えらべます（英語の 声で 読みながら、文字は 日本語 なども できます）。

- はじめる画面の「もじ」「こえ」と、**どの ページでも 上の「ことば」ボタン**（小さな パネルの「もじ」「こえ」の 2列）で えらべます。えらんだ 言葉は、そのあとの ページも つづきます（つぎに ひらいた ときも）
- もじ を かえても こえ は そのまま です（こえ だけ、もじ だけ を かえられる）。さいしょは スマホの 言葉（英語・ポルトガル語なら その言葉、ほかは 日本語）
- 読んでいる とちゅうに こえ を かえると、その ページを あたらしい 声で 読みなおします

- ボタン・ヒント・お知らせなど キットの言葉は、キットが訳します
- 絵本の文章・セリフ・名前などは、`lang/en.json`（英語）・`lang/pt.json`（ポルトガル語）に「日本語」：「訳」の組で書きます

```
npm run lang      # lang/en.json・pt.json を作る／新しい文を足す（訳のところは "" になる）
```

```json
{
  "ねこの ミミは やねの うえ。": "Mimi the cat is on the roof.",
  "おつきさま、こんばんは！": "Good evening, Moon!"
}
```

- 印刷された紙の文章は日本語のままです。もじ が ほかの言葉の ときは、絵の下の文章が **その言葉で AR に重なって出ます**（下の「もじ」ボタン）。「もじ」を消しているときは、読み上げる行の訳が画面の下に出ます（字幕）。声は こえ で えらんだ 言葉で 読みます（日本語の 声は 読み上げ原稿 read、英語・ポルトガル語の 声は lang の 訳）
- 文章やセリフを直したら、もう一度 `npm run lang` をして、新しく出てきた `""` に訳を書きます（`npm run check` で 訳のない文の数が出ます）
- 訳のない文は、日本語のまま出ます

## 声

- 文章を読む声：`book.json` の `"narrator"`
- 登場人物の声：`book.json` の `cast` の `"voice"`（`pitch` 高さ・`rate` 速さ。1 がふつう）
- **かわいい声（キットの標準）：** 子ども向けに、スマホに女の人の声があれば それを使い、みんなの声を少し高くします（それぞれの `pitch` の ちがいは そのまま）。ふつうの声にしたいときは `book.json` の `"settings"` に `"voice": "normal"`
- 声そのものはスマホに入っている読み上げ音声です。iPhone と Android、機種によって声が違います
- 高さの差を大きくしすぎると機械っぽくなります（0.85〜1.3 くらいがおすすめ）

## 画面のボタンとの関係

| ボタン | すること |
|---|---|
| よむ | いまのページの文章を読む（カメラで表紙を映しているときは「ページを めくって、この ページを うつしてね」） |
| セリフ | オンだと、ページが映ったときに自動で読み、登場人物のセリフもしゃべる。最初は オン（`settings.voiceOn` を `false` に すると 最初は オフ） |
| こうかおん | 効果音のオン／オフ |
| もじ | 絵の下の文章を、えらんだ言葉で AR に重ねて出す／かくす。日本語では はじめは かくす（紙の文章が読めるため）、ほかの言葉では はじめから出す。言葉を切りかえると、また はじめの決まりにもどる。読んでいる行は、出している文章の上で光る |

`settings.readFirst` が `true` のときは、ページを最初に映すと「おはなし」の時間になり、読み終わる（または「あそぶ」を押す）まで、さわっても動きません。
