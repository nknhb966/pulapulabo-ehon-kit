# 01 はじめかた（自分のパソコンで作る）

このキット（`pulapulabo-ehon-maker.zip`）を自分のパソコンで使って、AR 絵本を作る方法です（作りかた ③「ぜんぶ自分で作る」）。
プログラムを書いたことがなくても大丈夫です。最初の準備だけ少し手間がかかりますが、そのあとは「絵や文章を直す → コマンドを1つ打つ」のくり返しです。

> 同じキットを Claude に添付すれば、Claude に作ってもらうこともできます（キットの中の `つかいかた.md`）。Claude で作った絵本の絵だけを自分で描きかえるときは [09 自分の絵に描きかえる](09_自分の絵に描きかえる.md) を見てください。

## 1. 用意するもの

| もの | 説明 |
|---|---|
| パソコン | Windows でも Mac でも OK |
| Node.js | https://nodejs.org から「LTS」と書いてある方をインストール（バージョン 20 以上）。絵本を作る道具を動かすのに使います |
| VS Code | https://code.visualstudio.com 。ファイルを書きかえるアプリ。コマンドもこの中で打てます |
| このキット | `pulapulabo-ehon-maker.zip`（https://github.com/nknhb966/pulapulabo-ehon-kit からダウンロード） |

## 2. キットを置く

1. `pulapulabo-ehon-maker.zip` を展開（Windows：右クリック →「すべて展開」、Mac：ダブルクリック）します
2. できた `pulapulabo-ehon-maker` フォルダを、わかりやすい場所（「ドキュメント」など）に置きます
   - OneDrive・iCloud Drive などで自動で同期されるフォルダの中は、避けた方が安心です（たくさんのファイルを作るため）
   - 絵本ごとにキットを分ける必要はありません。1つのキットの中で何冊でも作れます

## 3. VS Code で開く

1. VS Code を開き、**ファイル → フォルダーを開く** で `pulapulabo-ehon-maker` フォルダを選びます
2. 「このフォルダー内のファイルの作成者を信頼しますか？」と出たら「はい」
3. 上のメニューの **ターミナル → 新しいターミナル** を開きます。下にコマンドを打つ場所が出ます

> メニューが英語のときは File → Open Folder、Terminal → New Terminal です。

## 4. 最初の準備（1回だけ）

ターミナルに、下の1行を打って Enter を押します（コピーして貼りつけても OK）。

```
npm install
```

作るための道具をダウンロードします（1〜2分）。`node_modules` というフォルダができれば OK です。

## 5. 見本を作ってみる

```
npm run build
```

「✅ できました」と出たら成功です。`publish/sample-svg/` に、見本「ねこと おつきさま」のできあがりが入ります。

```
publish/sample-svg/
  index.html                AR 本体（カメラで映す）
  preview.html              カメラなしで遊べる版
  ehon/                     プログラム・絵・データ（index.html と preview.html が使う）
  print/                    印刷用 PDF と画像
  THIRD_PARTY_LICENSES.txt  ライセンス表示
```

> はじめての「作る」は、画像認識データを作るので少し時間がかかります。絵を変えなければ、次からは速くなります。

## 6. パソコンで見る

**いちばん かんたん：** `publish/sample-svg/preview.html` をダブルクリックします。ブラウザが開いて、カメラなしで遊べます。

**カメラも試したいとき：**

```
npm run serve
```

ブラウザで **http://localhost:8080/** を開きます。パソコンにカメラがあれば、印刷したページを映して試せます。止めるときは、ターミナルで `Ctrl` + `C` を押します。

- このページでカメラが使えるのは、そのパソコンのブラウザだけです。同じ Wi-Fi のスマホから開いてもカメラは使えないので、スマホでは公開した URL で試します（[06 公開と印刷](06_公開と印刷.md)）

## 7. 自分の絵本を作る

```
npm run new-book -- my-book
```

見本がコピーされて `books/my-book` ができます。あとは説明書を見ながら書きかえます。

- 絵を **お絵かきアプリ（PNG）** で描くときは、`npm run png` で見本の絵を PNG にすると、位置や大きさの下絵として使えます。描いた絵は `npm run put-png -- 描いた絵のフォルダ` でまとめて入れられます（[09 自分の絵に描きかえる](09_自分の絵に描きかえる.md)）
- 文章・しかけ（`page.json`）だけ先に書いて、絵はあとから少しずつ描きかえても大丈夫です
- 設定（book.json・page.json）は、`npm run excel` でできる **Excel の表** で、▼ から えらびながら書くこともできます（[02 新しい絵本を作る の「表（Excel）で書く」](02_新しい絵本を作る.md#表excelで書く)）
- ベクターアプリ（Illustrator・Inkscape など）で描くときは `npm run svg` で SVG の下絵が出せます。`_ガイド.png`・`_ガイド.svg` を重ねると、奥行きの5列と文章の箱の場所が 分かります
- `npm run build` のあと `npm run preview` をすると、カメラなしの プレビューが 1つの ファイル（`out/<名前>_preview.html`）に なります。人に送って 見てもらうときに 便利です

|---|---|
| [02 新しい絵本を作る](02_新しい絵本を作る.md) | 絵本のフォルダ、book.json、ページの足し方 |
| [03 絵を用意する](03_絵を用意する.md) | SVG（プログラム）と PNG（お絵かきアプリ）での絵の作り方 |
| [04 文章と読み上げ](04_文章と読み上げ.md) | ページの文章、セリフ、読み上げ用の原稿 |
| [05 しかけ](05_しかけ.md) | さわったときの動き・音・遊び（コードなしで書ける） |
| [06 公開と印刷](06_公開と印刷.md) | 何を GitHub に上げるか、公開、印刷、うまくいかないとき |
| [07 困ったとき](07_困ったとき.md) | パソコンで作るときに よくあるトラブル |
| [08 部品カタログ](08_部品カタログ.md) | 使える部品の一覧（遊び・反応・演出など） |

できたら `npm run pack` で、`out/<名前>_github.zip`（GitHub に上げるもの）と `out/<名前>_source.zip`（元データ）ができます。

## 8. Claude と行き来する

- **Claude で作った絵本を、パソコンで直す：** `<名前>_source.zip` を `books/` の中に展開して（`books/<名前>/book.json` ができる）、`npm run use -- <名前>` を打ちます
- **パソコンで作った絵本の続きを、Claude に頼む：** `npm run pack` でできた `<名前>_source.zip` と、このキット（`pulapulabo-ehon-maker.zip`）を一緒に添付して、「この絵本の〇〇を直してください」と頼みます
- **Claude で作って、絵だけ自分で描く：** [09 自分の絵に描きかえる](09_自分の絵に描きかえる.md)
- **ChatGPT でも 同じです。** 添付する キットを ChatGPT 用キット（`pulapulabo-ehon-maker-chatgpt.zip`）に します

## 9. JSON や SVG を書くときのコツ

- VS Code で JSON（`book.json`・`page.json`）を開くと、書きまちがいに赤い波線が出ます
- SVG はメモ帳や VS Code で開くと中身が読め、ダブルクリックするとブラウザで絵として見られます

## よく使うコマンド

| コマンド | すること |
|---|---|
| `npm run new-book -- 名前` | 新しい絵本のフォルダを作る |
| `npm run add-page` | ページを1つ足す |
| `npm run check` | 絵本の設定にまちがいがないか調べる（作らない） |
| `npm run doctor` | このパソコンで キットの道具が 動くか 調べる（うまく 作れないときに） |
| `npm run build` | 絵本を作る（`publish/<絵本名>/` にできる） |
| `npm run serve` | できた絵本をパソコンで見る |
| `npm run sheet` | 各ページの絵を一覧にした画像を `out/` に作る |
| `npm run preview` | カメラなしの プレビューを 1つの ファイル `out/<名前>_preview.html` にする（`npm run pack` でも できる） |
| `npm run png` | すべての絵を PNG（2400×1800）にして `out/<名前>_png/` に出す。お絵かきアプリの下絵に（[09](09_自分の絵に描きかえる.md)） |
| `npm run svg` | すべての絵を SVG（1600×1200）のまま `out/<名前>_svg/` に出す。ベクターアプリの下絵に（[09](09_自分の絵に描きかえる.md)） |
| `npm run put-png -- フォルダ` | 描いた PNG・SVG を、同じ名前の絵と入れかえる（`put-svg` も同じ。[09](09_自分の絵に描きかえる.md)） |
| `npm run excel` | 絵本の設定を Excel の表 `out/<名前>_表.xlsx` にする（▼ で えらべる） |
| `npm run excel-in` | 直した表から book.json・page.json・read.json を作る（[02](02_新しい絵本を作る.md#表excelで書く)） |
| `npm run lang` | ほかの言葉の訳のファイル（`lang/en.json`・`pt.json`）を作る／新しい文を足す（[04 文章と読み上げ](04_文章と読み上げ.md)） |
| `npm run pack` | 作って、GitHub に上げる ZIP・元データの ZIP・1つにまとめた プレビューを作る |
| `npm run use -- 名前` | 作る絵本を切りかえる（`npm run use` だけだと一覧が出る） |

> 次の日に続きをするときは、VS Code で `pulapulabo-ehon-maker` フォルダを開いて、ターミナルを開くところからです。`npm install` はもう いりません。
