# 05 しかけ（さわったときの動き・遊び）

しかけは `page.json` に書きます。コードは書かなくて大丈夫です。

## 1. さわったときの反応（"touch"）

```json
"touch": {
  "cat":  { "move": "hop", "sound": "meow", "say": ["こんばんは！", "にゃーん♪"] },
  "tree": { "move": "wobble", "sound": "yusa", "word": "ゆさゆさ", "color": "#2f7d5b", "effect": "leaves" },
  "moon": { "move": "wobble", "sound": "chime", "swap": "awake", "back": 3 }
}
```

左の名前（`cat` など）は、飛び出す絵の id です。項目はどれも、なくてもかまいません。

| 項目 | 意味 | 例 |
|---|---|---|
| `move` | 動き（下の表）。`[ ]` で並べると、さわるたびに順番に ちがう動き（`say` の列と いっしょに進む） | `"hop"`、`["hop", "spin", "catJoy"]` |
| `sound` | 効果音（下の表） | `"kasa"` |
| `word` | 飛び出すオノマトペの文字。`[ ]` で並べると、さわるたびに順番に変わる | `"カサカサ"` |
| `color` | オノマトペの文字の色 | `"#4f9a5f"` |
| `wordAt` | `"touch"` にすると、オノマトペを絵の上ではなく、さわった場所に出す（大きな草むらなど） | `"touch"` |
| `say` | 吹き出しのセリフ。`[ ]` で並べると順番に変わる | `["やあ！", "またね"]` |
| `who` | セリフをしゃべる登場人物（book.json の cast の id）。その人の声になり、そのページにいれば 吹き出しも その人から出る。ふつうは書かなくて OK（絵と同じ id の登場人物） | `"cat"` |
| `swap` | 絵を切りかえる（`layers/<id>@<swap>.png` か `.svg`）。`[ ]` で並べると、さわるたびに順番に変わって、最後の絵でとまる（おべんとうが へっていく など）。このときは `say`・`word` の列も 絵といっしょに進んで、最後でとまる。`"base"` は もとの絵にもどす | `"awake"`、`["3", "2", "1", "0"]` |
| `back` | 何秒で元の絵に戻るか（書かないと 2.5秒）。`0` にすると、さわるたびに切りかわる。`false` にすると、もどらない | `3` |
| `effect` | 演出（下の表） | `"sparkle"` |
| `show` | かくれている絵（`"hidden": true`）を出す | `"rabbit"` |
| `hideAfter` | `show` で出した絵を、何秒後にまたかくすか | `3` |
| `mark` | 頭の 真上に 出る 気持ちのマーク（下の「気持ちのマーク」）。**セリフ（`say`）の ない 反応で** 使う（セリフが あると 出ない）。`[ ]` で並べると順番に変わる | `"heart"` |
| `walk` | 決めた点を通って歩く。もう一度さわると もどってくる（下の「歩く」） | `[[700, 800], [900, 820]]` |
| `light` | 明かりをつける／消す。`true` で自分、ほかの絵は id で（下の「明かり」） | `true`、`["window1", "window2"]` |
| `reveal` | 箱などが開いて、かくれている絵（`"hidden": true`）が中から飛び出す | `"kitten"` |
| `get` | もちものが手に入る（下の「もちもの」） | `"key"` |
| `need` | もちものを持っているときだけ この反応（ないときは `else`） | `"key"` |
| `give` | もちものを わたす（もちものから なくなる）。持っていないときは `else`（下の「ページをまたぐ しかけ」） | `"onigiri"` |
| `join` | なかまに なって、つぎの ページから ついてくる（下の「ページをまたぐ しかけ」） | `"kitten"` |
| `if` | 前に えらんだもの・かぞえた数・クリアしたページ などが 合うときだけ この反応（ちがうときは `else`。下の「ページをまたぐ しかけ」） | `{ "gift": "cake" }` |
| `else` | `need`・`if`・`give` に合わないときの反応 | `{ "say": "かぎが ない…" }` |
| `remember` | えらんだことにして覚えておく | `{ "gift": "cake" }` |
| `after` | ページをクリアしたあとの反応（下の「クリアの前と後」） | `{ "say": "やったね！" }` |
| `on` | さわった絵ではなく、ほかの絵が この反応をする（下の「つづけて動く」） | `"pendulum"` |
| `then` | 少しあとに つづけて起こること（下の「つづけて動く」） | `{ "delay": 1.5, "on": "dove", "word": "ポッポー" }` |
| `delay` | `then` の中で、前の動きから何秒あとか | `1.5` |
| `wait` | 何秒間、もう一度さわっても反応しないか（下の「押せない時間」）。ふつうは書かない | `2` |
| `lock` | 同じ名前を書いた絵を、まとめて止める（下の「押せない時間」） | `"clock"` |

### クリアの前と後（"after"）

ページの遊びをクリアしたあとは、`after` に書いた反応に変わります。登場人物のセリフを「遊ぶ前」と「クリアしたあと」で変えると、お話が進んだ感じが出ます。

```json
"cat": { "move": "hop", "sound": "meow", "say": ["みんな どこ？", "にゃーん♪"],
         "after": { "move": "bigHop", "sound": "meow", "say": ["みんな みつけたよ！", "おつきさま、みてて！"] } }
```

- クリアしたあとは `after` の中の項目だけが使われます（前の項目は引きつがれません）
- `after` のセリフの列は、1つめから順番に出ます

### つづけて動く（"then"・"on"）

「チクタク……ポッポー」のように、**間（ま）をあけて 次のことが起こる** ときは `then` を書きます。

```json
"clock": { "on": "pendulum", "move": "swing", "sound": "chikutaku", "word": "チクタク", "lock": "clock",
           "then": { "delay": 1.5, "on": "dove", "show": "dove", "hideAfter": 1.5, "sound": "poppo", "word": "ポッポー" } }
```

- `then` の中も、touch と同じ書き方です（`move`・`sound`・`word`・`say`・`swap`・`show` …）
- `delay` は、前の動きが始まってから何秒あとか（書かないと 0 ＝ 同時）
- いくつも続けるときは `[ ]` で並べます。`delay` は、ひとつ前から数えます
- `on` を書くと、その動きは さわった絵ではなく `on` の絵がします（はと時計をさわると ふりこが ゆれる、など）
- **最後の動きが終わるまで、もう一度さわっても反応しません**（とちゅうで やり直されて 動きが ばらばらに ならないように）。`wait` を書くと、その秒数に変わります

```json
"tansu": { "on": "drawer", "move": "pullOut", "sound": "gara", "word": "ガラッ", "lock": "drawer",
           "then": [ { "delay": 0.4, "show": "socks", "hideAfter": 1.1 },
                     { "delay": 1.1, "on": "drawer", "move": "pushIn", "sound": "patan", "word": "パタン" } ] }
```

（`pullOut`・`pushIn` は キットの動きです。下の「move（動き）」の表）

### 押せない時間（"wait"・"lock"）

小さな子どもは、同じ絵を何度も続けて さわります。キットは、次のように自動で決めます。**ふつうは何も書かなくて大丈夫です。**

| 反応 | もう一度さわると |
|---|---|
| `hop`・`bigHop`・`jump2`・`wobble`・`shake`・`pulse`、音・文字・セリフ・演出だけ | すぐに反応する（連打できる） |
| `spin`・`turn`・`swing`・`topple`・`roll`・`fly`・`slideLeft`・`slideRight`・`rise`・`open`、下の表の「とびだす」から「つみき」までの動き | 動きが終わるまで反応しない（途中でやり直すと絵がおかしくなるため） |
| `then` があるとき | 最後の動きが終わるまで反応しない |
| そのページの script.js で作った動き | 動きが終わるまで反応しない（動きが「何秒かかるか」を返すとき） |

- 反応しない間も、さわった所には 主人公の 手のあと（人の手・肉球・足あと）が出ます
- 変えたいときだけ `"wait": 秒` を書きます。`"wait": 0` にすると、長い動きでも連打できます。5秒より長くすると、こわれたと思われやすいので注意
- `"lock": "名前"` を書いた絵どうしは、まとめて止まります。たとえば、はと時計（`clock`）と ふりこ（`pendulum`）のどちらをさわっても同じ動きが始まるときは、両方に `"lock": "clock"` と書くと、動いている間はどちらも反応しません。止まる時間は、さわった方の `wait`（または動きの長さ）で決まります
- 遊び（goal）のタッチには、押せない時間はかかりません（なんども タッチが遊びになるため）

### move（動き）

どの動きも、小さな子が目で追える「少し ゆっくり」の はやさ（1回 はねる 0.7秒、1回 まわる 1.2秒）で、最後は なめらかに もとの位置へ もどります。

| 名前 | 動き | 名前 | 動き |
|---|---|---|---|
| `hop` | ぴょんとはねる | `bigHop` | 大きくはねる |
| `jump2` | 2回はねる | `wobble` | ゆらゆら |
| `shake` | ぶるぶる（4回 ゆれて とまる。ガタガタ・ぶるっ。コンコンと たたくのは `knock`） | `spin` | くるっと回る（縦の軸） |
| `turn` | くるっと回る（平面で） | `pulse` | ふくらむ |
| `swing` | ぶらぶら（吊り下げ向き） | `topple` | ぱたんと倒れて戻る |
| `roll` | ころころ転がって戻る | `fly` | くるっと飛び回る |
| `slideLeft` | 左へずれる（もう一度さわると戻る） | `slideRight` | 右へずれる（同じく） |
| `rise` | 下からせり上がる | `open` | ドアのように開く（もう一度で閉じる）。pieces で `"pivot": "left"` にすると左のはし、`"right"` にすると右のはしを軸に開く（ページの右がわの ドアは right）。へやの ドアは **外へ（かべの むこうへ）** 開く（戸口を くりぬき、外の けしきを `"depth"` の 絵に：guide/03 の「ドア」）。たんす・れいぞうこ など 手前に 開く 扉は pieces に `"opens": "in"` |

### mark（気持ちのマーク）

| 名前 | マーク | | 名前 | マーク |
|---|---|---|---|---|
| `!` | ！（びっくり・気がつく） | | `heart` | ハート（すき・うれしい） |
| `?` | ？（ふしぎ・こまった） | | `sweat` | あせ（あせる・こまった） |

| `idea` | ひらめき（電球） | | `angry` | ぷんぷん |

- マークは **セリフの ない とき** だけ 出ます（セリフが あると、セリフが 気持ちを つたえるので 出ません。`done` でも セリフを いう 人には 出ない）。頭の 真上に 出ます
- 吹き出しと マークは、キャラクターが くるっと 回ったり はねたり しても ぐるっと 動かず、歩くと なめらかに ついていきます（自動）

### 歩く（"walk"）

```json
"cat": { "walk": [[700, 800], [950, 820]], "sound": "pata" }
```

- 点は、ページの上の位置（左上が 0,0、右下が 1600,1200）です。**絵の足もと（いちばん下のまん中）** がその点を通ります
- 1回めにさわると点を通って歩いていき、もう一度さわると同じ道をもどってきます。歩いている間は、さわっても反応しません
- 向きを変えて歩かせたいときは `{ "points": [[700, 800]], "flip": true }`（進む向きに絵が左右反転。文字の入った絵には使わない）
- `parent` のある絵は歩けません

### 明かり（"light"）と夜（"dark"）

- `"light": true` でさわった絵、`"light": "window"` や `["w1", "w2"]` でほかの絵の明かりがつきます。もう一度で消えます
- 明かりがつくと、絵のうしろが あたたかく光ります。`<id>@on` の絵（明かりのついた窓など）があれば、その絵に切りかわります
- ページを暗くすると明かりが映えます。page.json に `"dark": 0.4`（0〜0.6）と書くと最初から暗いページ、`done` に書くとクリアしたときに暗くなります（`0` で明るくもどる）。明かりのついた絵は暗くなりません

### 中から出てくる（"reveal"）

```json
"pieces": [ { "id": "box" }, { "id": "kitten", "hidden": true } ],
"touch": { "box": { "reveal": "kitten", "sound": "gata" } }
```

- 出てくる絵（`kitten`）は、自分の場所に描いて `"hidden": true` にしておきます。さわると箱の位置から飛び出して、自分の場所に着地します
- `<箱の id>@open` の絵（ふたの開いた箱）があれば、その絵に切りかわります

## 2. ページの遊び（"goal"）

1ページに1つ、遊びを入れられます。クリアすると、ヒントの横に「できた！」が付き、お祝いの演出が出ます。

| type | 遊び | 向いている場面 |
|---|---|---|
| `find` | かくれているものを さがす | かくれんぼ、さがしもの |
| `gather` | 時間内に ぜんぶ タッチ | みんなを集める、急いで準備する |
| `mash` | なんども タッチ | 力を合わせる、重いものを動かす |
| `order` | じゅんばんに タッチ | かぞえる、順番どおりに進む |
| `choose` | えらぶ（クイズ） | 「〇〇は どれ？」、かずをかぞえる |
| `pop` | でてきたら タッチ | もぐらたたき、金魚すくい、ほたる・虫を つかまえる |
| `fall` | おちてくる ものを キャッチ | りんご・星・雪・どんぐりが ふってくる |
| `grow` | そだてる（だんだん変わる） | たね → め → はな、たまご → ひよこ |
| `dressup` | きせかえ | 服や色を選ぶ、お手本と同じにする |
| `rub` | こする・はらう | くもりをふく、雲やほこりをはらう |
| `carry` | はこぶ（指で うごかす） | おにぎりを 口へ、ボールを かごへ、にもつを とどける |
| `copy` | まねっこ（光った順に タッチ） | すずの おと、ドレミ、あいことば |
| `pairs` | ペアさがし（2まいずつ めくる） | おなじ くつした、おなじ どうぶつ、トランプ |
| `hold` | ながおし（ためる） | ふうせんを ふくらます、つりざおを ひく、パンを やく |
| `trace` | なぞって つなぐ | 星座、あみだ、形を かく |

- 時間や回数は、`book.json` の `"age"`（読む子の年れい）で自動で決まります（下の「遊びやすさ」）。決まった数にしたいときだけ、遊びの中に書きます
- しばらく進まないと、次にさわるものが光ります（自動ヒント）

### find：かくれているものを さがす

```json
"goal": {
  "type": "find",
  "items": [
    { "spot": "cloud", "item": "rabbit", "spotMove": "slideLeft", "say": "みつかっちゃった！" },
    { "spot": "tree", "item": "owl", "sound": "hoot", "say": "ホーホー" },
    { "spot": "star", "swap": "child", "say": "ぼく、ほしのこ だよ" }
  ],
  "done": { "toast": "ぜんぶ みつけたね！", "say": [{ "who": "moon", "text": "おやすみなさい" }] }
}
```

| 項目 | 意味 |
|---|---|
| `spot` | さわる場所（絵の id） |
| `item` | 出てくる絵（`pieces` で `"hidden": true` にしておく）。spot のうしろから せり上がる |
| `swap` | item のかわりに、spot の絵を切りかえる（`layers/<spot>@<swap>.png` か `.svg`） |
| `spotMove` | 見つけたときの spot の動き（move の名前）。書かないと ゆらゆら |
| `say` / `who` | 見つけたときのセリフと、しゃべる人 |
| `word` / `color` / `sound` | オノマトペ（ふつうは「みつけた！」。`false` で出さない）・色・音 |
| `react` | 見つけたときに、ほかにも起こすこと（touch と同じ書き方。`{ "effect": "firework", "mark": "heart" }` など） |
| `comeOut` | 見つかった item の 出かた。`"front"`＝spot の うしろから 横へ出て、**spot の 少し手前の 地面に立つ**（人・ねこ・いぬ）。`"here"`＝**その場所から 見える**（木に とまった とり・雲の うしろの うさぎ・ほたる）。書かないと キットが決めます：item の足もとが spot の足もと あたり（地面）なら front、spot の 上のほう・空・飛ぶ／光る絵なら here |
| `area` | spot の **この あたりを さわったときだけ** 見つかる `[左, 上, 右, 下]`（ページの ピクセル）。屋台の どこを さわっても 見つかる…を むずかしくする |

見つけたあとに item をさわったときの反応は、`"touch"` に書きます。

#### かくれんぼを 少し むずかしく（屋台の うしろの おかあさん）

どこを さわっても すぐ 見つかると、かんたんすぎます。次の しかけを 組み合わせます。

```json
"goal": {
  "type": "find",
  "items": [
    { "item": "mama", "clue": "mama_clue",
      "places": [
        { "spot": "yatai_wata", "area": [240, 335, 418, 700], "at": [320, 686], "peek": [388, 524], "flip": true },
        { "spot": "yatai_yoyo", "area": [594, 258, 780, 690], "at": [697, 676], "peek": [629, 514] },
        { "spot": "yatai_omen", "area": [1134, 308, 1320, 708], "at": [1237, 694], "peek": [1169, 532] }
      ],
      "call": { "say": "いちろう〜", "after": 10 },
      "say": "いちろう！ ここよ！", "who": "mama" }
  ],
  "misses": [
    { "spot": "yatai_yoyo", "react": { "swap": "pop", "back": 2, "word": "ぽよーん", "then": { "on": "ichiro", "say": "なんだ、ヨーヨーかぁ" } } }
  ],
  "done": { "toast": "おかあさん みつけた！" }
}
```

| 項目 | 意味 |
|---|---|
| `places` | かくれる場所の 候補。**あそぶ たびに ちがう場所**に かくれます。`spot`（さわる絵）・`area`（さわる あたり）・`at`（かくれている ときの 足もと [x, y]。spot の うしろ）・`peek`（手がかりの絵の 下の はし [x, y]）・`flip`（手がかりを 左右反対に。右の はしで 使う）。item は parent なしの 絵にします |
| `clue` | **ちらっと 見える 手がかり**の絵（`"hidden": true`。紙には 印刷されない）。かくれている spot の うしろに おかれ、spot から はみ出た ところ（屋台の はしから あたまの はし・しっぽ など）だけ 見えて、ときどき ゆれます。さわっても 見つかります |
| `call` | しばらく 見つからない（`after` 秒）か、3回 はずれると、かくれている所から 声（`say`・`sound`）がして、その場所が ゆれます。`every` で くりかえす間 |
| `misses`（遊びに書く） | はずれの 反応。いない 場所を さわると、その絵の 楽しい反応（ヨーヨーが ぽよーん・おめんが ばあ！）。書かない場所は「いないみたい」と ゆれます（`miss` で かえられる） |

- 人は 見つかると 屋台の 横から出て、**屋台の 少し手前に 立ちます**（`comeOut` が front）。木に かくれた フクロウなら その木の ところで 見えます（here）
- 手がかりの絵は、かくれている 人の 一部（あたまと かんざし・そで・しっぽ）を、その絵と 同じ大きさで 描きます
- **2つ以上 さがすとき：** 1つ 見つけたら、まだの ほうを さがす セリフに かえます。`"if": { "found": "mama" }`（mama を 見つけた あと）と `"else"`（まだのとき）で わけます

```json
"ichiro": {
  "if": { "found": "mama" }, "say": ["ミケは どこかな？", "ミケ〜、どこ〜？"],
  "else": { "say": ["おかあさーん！ どこー？", "ど、どうしよう…"] },
  "after": { "say": "もう まいごに ならないよ" }
}
```

  `misses` の 反応の セリフ（`then` の中）も 同じように わけます。check が「みつけた あとも 出ます」と 知らせます

遊びに `"count": "found"` を書くと、見つけた数を ほかのページで使えます（下の「ページをまたぐ しかけ」）。

### gather：時間内に ぜんぶ タッチ

```json
"goal": {
  "type": "gather",
  "targets": ["cat", "rabbit", "owl", "star"],
  "seconds": 8,
  "react": {
    "cat":    { "move": "bigHop", "sound": "meow", "say": "おちゃかいだよ！" },
    "rabbit": { "move": "jump2", "sound": "boing", "word": "ぺったん", "say": "おもち もってきたよ" },
    "star":   { "swap": "child", "move": "pulse", "sound": "kirarin", "say": "キラキラ、きたよ" }
  },
  "again": { "cat": { "move": "hop", "say": "みんな まだかな？" } },
  "undo":  { "cat": { "word": "まだかな…", "color": "#7a5aa0" } },
  "done": { "toast": "みんな あつまったね！", "effect": "sparkle" }
}
```

タッチした絵の横に「OK」と、減っていく丸い時計が出ます。`seconds` 秒たつと元に戻ります。全部そろうとクリア。

| 項目 | 意味 |
|---|---|
| `targets` | タッチする絵の id |
| `seconds` | 何秒で元に戻るか（年れいで自動。5さいは 8） |
| `react` | **相手ごとの、タッチしたときの反応**（touch と同じ書き方）。`swap` は、そろっている間ずっとその絵になり、時間切れで元に戻る。書かない相手は「はねる＋鳴き声（ポン）」 |
| `again` | そろっている間に、もう一度タッチしたときの反応（相手ごと）。書かない相手は小さくゆれる |
| `undo` | 時間切れで元に戻ったときの反応（相手ごと。`word`・`say`・`move`・`sound` など）。書かない相手は「あれれ？」 |
| `readyWord` | 時計の中の文字（ふつう OK） |
| `undoWord` | `undo` を書かない相手の、時間切れの文字（ふつう「あれれ？」） |

### mash：なんども タッチ

```json
"goal": { "type": "mash", "target": "bigcloud", "times": 10, "doneMove": "flyAway", "word": ["フーッ", "えいっ"] }
```

| 項目 | 意味 |
|---|---|
| `target` | タッチする絵 |
| `times` | 何回でクリアか（年れいで自動。5さいは 10） |
| `decay` | タッチをやめたとき、メーターが1秒に減る量（ふつう 0.04） |
| `doneMove` | クリアしたときの動き：`rollAway`（転がっていく）／`flyAway`（飛んでいく）／`pop`（ポンと消える）／`none`、または move の名前（そのページの script.js の動きも。消すときは その動きの中で `pg.hide`） |
| `tapMove` | タッチするたびの target の動き（書かないと ぶるっと ゆれる）。move の名前（そのページの script.js の動きも） |
| `word` | タッチするたびに出る文字（ならべると 順番に）。文字は target の まわり（左右・上）の いろいろな場所に 毎回 ちがう所へ 出ます。ほかの 登場人物や メーターには 重なりません（そだてる・ながおし も 同じ） |
| `gauge` | メーターの文字（ふつう「ちから」） |

**みんなで おす（`team`）**：先に みんなを タッチしてから、`target` を なんども タッチする遊びになります（大きな いわを みんなで おす など）。

```json
"goal": { "type": "mash", "target": "bigRock", "team": ["ma", "hi", "me", "su"], "readyWord": "うーん",
          "react": { "ma": { "swap": "push", "say": "せーの！" } },
          "win":   { "ma": { "swap": "fall", "word": "ドテッ" } } }
```

| 項目 | 意味 |
|---|---|
| `team` | 先に タッチする絵の id。タッチすると、`seconds`（年れいで自動。5さいは 8秒）のあいだ がんばる。ぜんぶ そろうまで target は「びくとも しない」 |
| `readyWord` | がんばっている間の丸い時計の文字（ふつう「OK」） |
| `react` / `again` / `undo` | 絵ごとの反応：はじめに タッチしたとき／もう一度／つかれて やめたとき（gather と同じ） |
| `win` | target が動いたときの、絵ごとの反応（ころぶ など） |

- target を タッチするたびに、みんなの時計が もとにもどる（おうえんで がんばれる）
- だれかが つかれて やめると、メーターは 0 にもどる

### order：じゅんばんに タッチ

```json
"goal": { "type": "order", "targets": ["one", "two", "three"], "words": ["いち", "に", "さん"] }
```

`targets` の順番にタッチします。正しくタッチした絵には番号が付きます。順番をまちがえると「ちがうよ」とゆれます。

| 項目 | 意味 |
|---|---|
| `targets` | タッチする順番の絵の id（2つ以上） |
| `words` | タッチしたときの文字（順番に）。書かないと 1・2・3… |
| `react` | 相手ごとの反応（touch と同じ書き方）。書かないと「はねる＋ポン」 |
| `strict` | `true` にすると、まちがえたら最初からやり直し（7さいは自動で `true`） |
| `wrongWord` | まちがえたときの文字（ふつう「ちがうよ」） |

### choose：えらぶ（クイズ）

```json
"goal": { "type": "choose", "question": "おつきさまは どれ？", "options": ["moon", "sun", "lamp"], "answer": "moon", "who": "cat",
          "wrong": { "sun": { "say": "それは おひさま！", "move": "wobble" } } }
```

遊びが始まると、`who` の登場人物が問題を言います（`who` がないと画面の上に出ます）。正しい絵をタッチするとクリア。まちがえても何度でも選べます。

**1問で おわらせず、2〜3問 つづけるのが おすすめです。** `questions` に 問題を ならべると、1問 正解するごとに 次の問題が 出て、ぜんぶ 正解で クリアです。`answer` を `["a", "b"]` にすると **正解が いくつも**あり、ぜんぶ 見つけると 次へ（「あかい ものは どれ？ ぜんぶ さがしてね」）。

```json
"goal": { "type": "choose", "options": ["hanabi_maru", "hanabi_star", "hanabi_heart", "hanabi_neko"],
  "questions": [
    { "question": "ハートの はなびは どれ？", "answer": "hanabi_heart", "who": "mama", "wrong": { "hanabi_star": { "say": "それは おほしさま！" } } },
    { "question": "おほしさまの はなびは どれ？", "answer": "hanabi_star", "who": "ichiro" },
    { "question": "まるい はなびと ねこの はなびは？", "answer": ["hanabi_maru", "hanabi_neko"], "who": "neko" }
  ],
  "done": { "toast": "ぜんもん せいかい！" } }
```

- 問題ごとに `question`・`answer`・`who`・`options`・`right`・`wrong`・`react` を書けます（書かないものは 遊びの方の 値）。正解の数だけ 点（せいかい ●●●）が 出ます

| 項目 | 意味 |
|---|---|
| `question` | 問題の文（ヒントの場所にも出る） |
| `options` | 選ぶ絵の id（2つ以上） |
| `answer` | 正解の id。`["a", "b"]` なら 正解が いくつも（ぜんぶ 見つけて クリア）。**書かないと、どれを えらんでもクリア**（「どっちに する？」のように えらぶだけ） |
| `questions` | 問題を つづけて出す `[{ "question", "answer", … }, …]`。ぜんぶ 正解で クリア |
| `who` | 問題を言う登場人物 |
| `remember` | えらんだものを覚えておく名前（例：`"gift"`）。あとのページで `"if"` やセリフの `{gift}` に使う（下の「えらんだ方で変わる」） |
| `names` | えらぶものの名前 `{ "cake": "ケーキ", "flower": "おはな" }`（`{gift}` に入る。もちもの・登場人物なら書かなくても OK） |
| `react` | えらんだものごとの反応 `{ "cake": { "say": "おいしそう！" } }` |
| `right` | 正解したときの反応（touch と同じ書き方）。書かないと「大きくはねる＋キラリン＋せいかい！」 |
| `wrong` | まちがえたときの反応（id ごと）。書かないと「ゆれる＋ちがうみたい」 |

- かずの問題は、数字のカード（`n2`・`n3`・`n4` など）を絵として描いて `options` にします
- 自動ヒントでは、問題をもう一度言って、選ぶ絵が光ります（答えは教えません）

### もちもの（ページをまたいで持っていく）

`book.json` に もちものを書きます。

```json
"items": [{ "id": "key", "name": "かぎ" }]
```

- `"get": "key"` … 手に入れる。touch の反応、find の items（見つけたとき）、done（クリアしたとき）に書けます。画面の右上の もちもの に 絵が入ります（絵は `items/key.svg`、なければ同じ id の飛び出す絵）
- `"need": "key"` … 持っているときだけ、その反応が起きます。持っていないときは `"else"` の反応

```json
"door": { "need": "key", "move": "open", "say": "かぎで あいた！",
          "else": { "move": "shake", "say": "かぎが かかっている…" } }
```

- AR では ページを好きな順に映せるので、持っていないとき（`else`）の反応も必ず書きます
- 「さいしょから」で もちものは空になります
- **もちものの絵**（おべんとう・ちょうちん・きんぎょの ふくろ）が もらった ページより あとの ページに あるときは、その絵の `pieces` に `"need": "bento"` を書きます。紙には そのまま 印刷されますが、**AR では 持っていないと 出ません**（おべんとうを わすれて 来たのに おべんとうが ある…に ならない）。持っていないときの ひとことは、持ち主の 登場人物の touch の `else` に書きます
- 登場人物が 持っている物は、登場人物の絵に 描きこまず、べつの絵（`"parent": "ichiro"`）に 分けます。ばんざい など ポーズで 持ち方が かわるときは、`<物>@<ポーズ>.svg`（例：`kingyo_bag@banzai.svg`）も 描くと、登場人物が `@banzai` に なると いっしょに かわります

### えらんだ方で変わる

えらんだものは、ほかのページで使えます。

- choose に `"remember": "gift"` を書く（または touch に `"remember": { "gift": "cake" }`）
- `"if": { "gift": "cake" }` … ケーキを えらんでいたときだけ その反応。ちがうときは `"else"`
- セリフ・お知らせに `{gift}` と書くと、えらんだものの名前が入る（[04 文章と読み上げ](04_文章と読み上げ.md)）

```json
"cat": { "if": { "gift": "cake" }, "say": "ケーキ、いっしょに たべよう！",
         "else": { "say": "{gift}、ありがとう！" } }
```

### ページをまたぐ しかけ

ページで したことを 覚えておいて、ほかのページで 使えます（「さいしょから」で ぜんぶ わすれます）。**AR では ページを 好きな順に 映せるので、合わないときの `else` を必ず書き、どの順番でも 遊べるように します。**

| したこと | 書きかた | ほかのページで |
|---|---|---|
| もちものを 手に入れる | `"get": "wallet"` | `"need": "wallet"`、遊びの道具 `tool`（上の「道具と手」） |
| もちものを わたす（なくなる） | `"give": "onigiri"` | 持っていないときは `else` |
| えらぶ | choose の `"remember": "gift"` | `"if": { "gift": "cake" }`、セリフの `{gift}` |
| かぞえる | 遊びの `"count": "fish"`（pop・fall・find・carry） | `"if": { "fish": 3 }`（3こ以上。`">=3"`・`"<3"`・`"=0"` も）、セリフの `{fish}` |
| なかまに なる | `"join": "kitten"`（touch など） | `"if": { "joined": "kitten" }` |
| きせかえ | dressup の `"keep": true` | 同じ id の絵が、ほかのページでも 同じ 見た目（`<id>@<見た目>` の絵が あるとき） |
| ページを クリア・ページを 見る | （自動） | `"if": { "cleared": 2 }`・`"if": { "seen": [1, 2] }` |
| スタンプを あつめる | （自動） | `"if": { "stamps": "all" }`（ぜんぶ）・`"if": { "stamps": 3 }` |
| このページの さがす（find）で 見つけた | （自動） | `"if": { "found": "mama" }`（mama を 見つけた あと）・`"if": { "found": ["mama", "neko"] }`（両方） |

`if` は、touch の反応・done（クリアのとき）・かくれている絵 に 書けます。

- **かくれている絵に `if`・`need`：** pieces で `"hidden": true` の絵に 書くと、ページを 映したとき、合っていれば 出てきます（なかまが ついてくる・数だけ 金魚が いる・道具を もっている）

```json
"pieces": [
  { "id": "kitten", "hidden": true, "if": { "joined": "kitten" } },
  { "id": "fish1", "hidden": true, "if": { "fish": 1 } },
  { "id": "fish2", "hidden": true, "if": { "fish": 2 } },
  { "id": "fish3", "hidden": true, "if": { "fish": 3 } }
]
```

- **done に `if`・`need` と `else`：** 合わないときは `else` の おしまいに なります（ぜんぶの ページで あそぶと 大きな お祝い）

```json
"done": {
  "if": { "stamps": "all" },
  "say": [{ "who": "cat", "text": "ぜんぶの ページで あそんでくれて ありがとう！" }],
  "effect": "starry",
  "else": { "say": [{ "who": "cat", "text": "{hotaru}ひき つかまえたね" }], "effect": "night" }
}
```

- **わたす：** 持っていると わたして 反応、ないときは `else`

```json
"friend": { "give": "onigiri", "move": "hop", "say": "おにぎり ありがとう！",
            "else": { "say": "おなか すいたなあ" } }
```

### pop：でてきたら タッチ

```json
"goal": { "type": "pop", "targets": ["mole1", "mole2", "mole3"], "word": ["ポン！", "つかまえた！"] }
```

`targets` の絵が1つずつ、下からぴょこっと出てきます。かくれる前にタッチすると1回。決まった回数つかまえるとクリアして、みんなが出てきます。

| 項目 | 意味 |
|---|---|
| `targets` | 出てくる絵の id。**pieces で `"hidden": true` にします**（紙に印刷されないように） |
| `times` | 何回つかまえたらクリアか（年れいで自動） |
| `stay` | 出ている秒数（年れいで自動） |
| `together` | 同時に出る数（ふつう 1） |
| `word` | つかまえたときの文字 |
| `react` | 相手ごとの、つかまえたときの反応 |
| `style` | 出かた：`"rise"`（下から ぴょこっ。もぐら。書かないと これ）・`"swim"`（よこから 泳いで来て もぐる。金魚）・`"fly"`（ふわっと 飛んで来て、ゆらゆら。ほたる・ちょう） |
| `behind` | かくれる場所：手前に立つ絵の id（草むら・穴の ふち・水そうの ふち）。`targets` は その うしろ（少し上）に描きます。出てくるときは その絵より 上まで のぼり、もどるときは うしろへ かくれます。その絵や まわりを タッチしても、近くに出ている相手を つかまえられます |
| `into` | つかまえた ものが 入る絵の id（金魚ばち・かご・びん）。つかまえるたびに 中に たまって 見えます。光る相手（pieces で `"glow": true`）なら 入れ物も だんだん 明るくなります |
| `tool` | 道具と手（下の「道具と手」）。ポイ・ハンマー・あみ などで あそぶ |
| `count` | つかまえた数を 覚える名前（`"fish"`）。セリフの `{fish}` や、ほかのページの `"if": { "fish": 3 }` で使えます |

```json
"goal": {
  "type": "pop", "style": "fly", "targets": ["ff1", "ff2", "ff3"], "behind": ["kusa1", "kusa2"], "into": "bin",
  "together": 2, "count": "hotaru",
  "tool": { "id": "net", "from": "dango", "who": "owl", "say": "おだんご、ありがとう！ この あみを つかってね" }
}
```

（見本 4ページ：ほたるが 草むらの うしろから 出てきて、タッチすると びんに たまる。2ページで おだんごを もらっていると、ふくろうが あみと こうかんして くれる）

### 道具と手（"tool"）

`pop`・`fall` では、もちものの道具で あそべます。道具が ないときは 手で あそびます（すくう・たたく）。**どちらでも 遊び全体は同じように できます。**

| 項目 | 意味 |
|---|---|
| `id` | 道具の もちもの（book.json の `items` に書く）。持っていると、タッチした所で 道具が 動き、相手から 少し はなれていても つかまえられます（少し やさしく なる） |
| `from` | こうかんする もちもの。遊びが はじまるとき、これを 持っていると `who` に わたして（もちものから なくなる）、道具を もらいます |
| `who` | 道具を くれる人（このページに いる 登場人物）。いないと、ことばだけ 画面に出ます |
| `say` | 道具を くれるときの セリフ（書かないと「○○を ありがとう！ △△を どうぞ」） |
| `hand` | 道具が ないときの ことば（書かないと「てで そっと つかまえよう！」か「てで ポンと たたこう！」） |
| `use` | 道具の 動き：`"scoop"`（すくう：ポイ・あみ）・`"whack"`（たたく：ハンマー）。書かないと、`rise` は たたく、ほかは すくう |

- 道具の絵は `items/<id>.svg`（もちものの絵）。ない ときは、キットの絵（`net`・`poi`・`hammer` という id なら その絵）を使います
- **手は 主人公の手** です（ネコなら ネコの手、クマなら クマの手）。キットが 主人公（book.json の `cast` の 1人め）の `id`・`name`・`look`・`about` の 言葉から えらびます：ねこ → `cat`、いぬ・きつね・たぬき → `dog`、くま・パンダ → `bear`、うさぎ・りす・ねずみ → `rabbit`、とり・ひよこ・ペンギン → `bird`、ほかは 人の手（`human`）
  - タッチした ところに 出る **手のあと**（ぽん と 出る 小さな あと）も この 手です（人なら 人の 手、ネコなら 肉球、とりなら 足あと）。色を かえるときは `"hand": { "kind": "human", "print": "#ff9a76" }`
  - ちがうときは `book.json` に `"hand": "cat"` を書きます。色を 主人公に 合わせるときは `"hand": { "kind": "cat", "color": "#fffaf0", "pad": "#ffb3c8" }`（`color` 手の色、`pad` 肉球の色）
  - キットに ない 手（カエル・ゾウ など）は、`items/hand.svg` に 主人公の手を描きます（その絵が 使われます）
- タッチは 少し はなれていても 近くの相手を つかまえます（道具なら もっと はなれていても）。かくれはじめて すぐ（0.5秒）なら まだ つかまえられます
- 道具（または `from`）を 手に入れる ページを ほかに 作ります（`get`）。AR では ページを 好きな順に 映せるので、道具が なくても 手で あそべるように なっています

### fall：おちてくる ものを キャッチ

```json
"goal": { "type": "fall", "targets": ["apple1", "apple2", "apple3"], "into": "basket", "word": ["キャッチ！"] }
```

`targets` の絵が 空から 1つずつ おちてきます。地面に つく前に タッチすると キャッチ。`targets` は pieces で `"hidden": true` にして、地面に おちた所（おちる先）に描きます。`times`（何回で クリア。年れいで自動）・`stay`（おちる時間は この2倍）・`together`・`into`・`tool`・`count`・`react` は pop と同じです。

### carry：はこぶ

```json
"goal": { "type": "carry", "items": ["onigiri"], "to": "me", "react": { "onigiri": { "move": "hop", "sound": "mogu", "say": "いただきます！" } } }
```

`items` の絵を 指で おしたまま うごかして、`to` の絵の ところで はなすと とどきます（とどいた物は 中に 入って 消えます。`"stay": true` なら そこに のこる）。全部 とどけると クリア。とちゅうで はなすと もとの 場所に もどります。

| 項目 | 意味 |
|---|---|
| `items` | はこぶ絵の id（parent の ない絵） |
| `to` | とどけ先の絵の id。物ごとに ちがうときは `{ "onigiri": "me", "ball": "basket" }` |
| `react` | とどいたとき、とどけ先が する反応（物ごと） |
| `reach` | どれくらい 近くで はなせば とどくか（ふつう 0.1。ページの はば 1 に対して） |
| `count` | とどけた数を 覚える名前 |

### copy：まねっこ

```json
"goal": { "type": "copy", "targets": ["bell1", "bell2", "bell3"] }
```

`targets` が 1つずつ 光って 音が なります（絵ごとに ちがう音）。おわったら 同じ順番で タッチ。まちがえると、もう一度 見せてくれます。`rounds`（おぼえる数の ならび。年れいで自動：3さい [2, 3]、5さい [3, 4]、7さい [3, 4, 5]）を ぜんぶ できると クリア。

### pairs：ペアさがし

```json
"goal": { "type": "pairs", "cards": ["apple1", "apple2", "star1", "star2"] }
```

`cards` が うらがえしで ならびます。2まいずつ めくって、同じ絵が そろうと のこります。ぜんぶ そろうと クリア。絵は 毎回 まぜるので、場所が かわります。

- `cards` は pieces で `"hidden": true` にします（紙に 答えが 印刷されないように）。全部 同じ大きさの カードの形（四角を ぬりつぶした絵）に 描きます
- ペアは、同じ名前に 番号を付けた id（`apple1`・`apple2`）か、`"pairs": [["c1", "c3"], ["c2", "c4"]]` で 決めます
- 紙には、カードを ならべる台（テーブル・しきもの）を 背景に 描いておくと 分かりやすくなります

### hold：ながおし

```json
"goal": { "type": "hold", "target": "balloon", "motion": "grow", "swap": "big", "doneWord": "ぷくー！" }
```

`target` を 指で おしたままに すると、メーターが たまって 絵が 変わっていきます。はなすと ゆっくり もどります。いっぱいに なると クリア。

| 項目 | 意味 |
|---|---|
| `motion` | `"grow"`（ふくらむ。書かないと これ）・`"pull"`（上へ ひっぱる：つりざお・かぶ）・`"shake"`（ぶるぶる ふるえる） |
| `grow` | ふくらむ 大きさ（ふつう 1.5） |
| `seconds` | おしつづける 秒数（年れいで自動：3さい 2秒、5さい 2.5秒、7さい 3秒） |
| `swap` | いっぱいに なったときの絵（`<id>@<名前>`） |
| `word`・`doneWord` | おしている間の文字・できたときの文字 |

### trace：なぞって つなぐ

```json
"goal": { "type": "trace", "points": [[300, 300], [500, 250], [700, 320], [900, 260]], "show": "bear" }
```

ページに 光る点が 出ます。1つめから 順番に 指で なぞる（または 順番に タッチする）と 線で つながります。ぜんぶ つなぐと クリア。

| 項目 | 意味 |
|---|---|
| `points` | 点の場所 `[x, y]`（ページの左上が 0,0、右下が 1600,1200）か、絵の id |
| `close` | `true` で、さいごに 1つめの点へ もどる（まるい形） |
| `color` | 線の色 |
| `show` | できあがったときに 出てくる絵（`"hidden": true` にした 星座の絵 など） |

### grow：そだてる

```json
"goal": { "type": "grow", "target": "seed", "stages": ["sprout", "bud", "flower"], "words": ["にょきっ", "ぷくっ", "さいた！"] }
```

`target` を何回かタッチするごとに、絵が `stages` の順に変わります（`seed@sprout` → `seed@bud` → `seed@flower`）。最後まで変わるとクリア。

| 項目 | 意味 |
|---|---|
| `target` | そだてる絵の id |
| `stages` | 変わっていく絵の名前（`<target>@<名前>` の絵を用意する） |
| `times` | 1段階に必要なタッチの回数（年れいで自動） |
| `words` | 変わったときの文字（段階ごと） |
| `gauge` | メーターの文字（ふつう「そだつ」） |

### dressup：きせかえ

```json
"goal": { "type": "dressup", "looks": { "hat": ["blue", "yellow"], "shirt": ["stripe"] }, "answer": { "hat": "yellow", "shirt": "stripe" } }
```

タッチするたびに、絵が「もとの絵 → `hat@blue` → `hat@yellow` → もとの絵…」と順に変わります。`answer` と同じにするとクリア。お手本の絵（`model` など）を別に描いておくと、子どもが見比べられます。

| 項目 | 意味 |
|---|---|
| `looks` | 着せかえる絵と、その見た目の名前 `{ "id": ["見た目", …] }` |
| `answer` | クリアの見た目 `{ "id": "見た目" }`（もとの絵は `"base"`）。書かないと、全部の見た目を試したらクリア |
| `keep` | `true` で、えらんだ見た目を ほかのページでも そのままにする（ほかのページにも `<id>@<見た目>` の絵を描く） |

### rub：こする・はらう

```json
"goal": { "type": "rub", "targets": ["fog1", "fog2"], "word": ["ゴシゴシ", "キュッキュッ"] }
```

指でこすると、メーターがたまり、いっぱいになると絵が消えます（`swap` を書くと、その絵に変わる）。全部きれいにするとクリア。タッチするだけでも少しずつ進みます（カメラで遊ぶときに手がふるえても大丈夫なように）。

| 項目 | 意味 |
|---|---|
| `targets` | こする絵の id |
| `swap` | きれいになったときに変わる絵の名前（`<id>@<名前>`）。書かないと消える |
| `amount` | こする量（年れいで自動） |
| `word` | こすっているときの文字 |
| `particle` | こすっているときに出る粒の色 |

### done（クリアしたとき）— どの遊びでも共通

```json
"done": {
  "toast": "まんまるの おつきさまが でてきたね！",
  "say": [{ "who": "moon", "text": "ありがとう" }, { "who": "cat", "text": "おやすみなさい" }],
  "move": { "door": "open" },
  "trail": { "points": [[800, 440], [795, 540], [805, 620], [795, 700]], "color": "#fff3b0" },
  "effect": "sparkle"
}
```

```json
"done": {
  "say": [{ "who": "cat", "text": "ただいま！" }],
  "walk": { "cat": [[1150, 820]] },
  "light": ["window"],
  "dark": 0.45,
  "mark": { "cat": "heart" },
  "effect": "night"
}
```

| 項目 | 意味 |
|---|---|
| `toast` | 上に出る文 |
| `say` | セリフの列 `[{ "who": "moon", "text": "…" }]`。順番に出る |
| `effect` | `"sparkle"`（キラキラ）・`"fireworks"`（花火）・`"finale"`（大フィナーレ：花火の連発、空いっぱいのきらきら、最後に大きな金色の花火。にぎやかなお話の最後のページ向け）、または下の「気分に合わせた おしまい」 |
| `move` | クリアしたときに動かす絵と動き `{ "絵の id": "move の名前" }`。ドアが開く（`open`）、雲が飛んでいく（`fly`）など |
| `trail` | 光の道。`points` はページの上の点（左上が 0,0、右下が 1600,1200）を2つ以上、`color` は色 |
| `walk` | 歩いていく絵と点 `{ "cat": [[1150, 820]] }`（上の「歩く」） |
| `light` | 明かりがつく絵 `["window", "lamp"]` |
| `dark` | ページが暗くなる（0〜0.6。`0` で明るくもどる） |
| `mark` | 気持ちのマーク。`"heart"` でみんな、`{ "cat": "heart", "owl": "zzz" }` で1人ずつ |
| `get` | もちものが手に入る `"key"`（上の「もちもの」） |
| `if`・`need`・`else` | 合うときだけ この おしまい。合わないときは `else` の おしまい（上の「ページをまたぐ しかけ」） |
| `face` | 登場人物の表情。書かないと、`<id>@happy` の絵がある登場人物は自動で笑顔になる。ほかの名前（`"cheer"` など）も書ける。`false` で変えない |
| `sound` | 音（ふつう fanfare） |
| `hop` | `false` にすると、登場人物がはねない |

> 笑顔の絵（`<id>@happy`）は、ページごとに `layers/` に置きます（[03 絵を用意する](03_絵を用意する.md) の「表情の絵」。目と口に しるしを付けた SVG なら自動でできます）。

**気分に合わせた おしまい**（`effect`）

| 名前 | おしまい | 合うお話 |
|---|---|---|
| `night` | 流れ星がいくつも流れ、きらきらがふる | おやすみ・夜のお話 |
| `starry` | 流れ星が たくさん流れ、星が ふりそそぎ、さいごに 大きな金色の流れ星 | 夜のお話の いちばん さいご・ぜんぶ クリアした お祝い |
| `celebrate` | 紙ふぶきがふる | おたんじょうび・おまつり・できたね |
| `spring` | 花がさくように花びらがはじけ、舞う | 春・花・たね |
| `sea` | あわが下からたくさんのぼる | 海・水・おふろ |
| `rainbow` | 空に にじがかかる | 雨あがり・なかなおり・ぼうけんの おわり |

## 3. 遊びやすさ（年れい・ヒント・ひかえめモード）

### 年れい（book.json の "age"）

```json
"age": 5
```

読む子の年れいを `3`・`5`・`7` から選ぶと、遊びの時間や回数が自動で決まります（書かないと 5）。

| | 3 | 5 | 7 |
|---|---|---|---|
| gather の時間 | 12秒 | 8秒 | 6秒 |
| mash の回数 | 6回 | 10回 | 14回 |
| pop・fall の回数 ／ 出ている時間 | 5回 ／ 2.6秒 | 6回 ／ 1.8秒 | 8回 ／ 1.3秒 |
| copy の おぼえる数 | 2 → 3 | 3 → 4 | 3 → 4 → 5 |
| hold の おしつづける時間 | 2秒 | 2.5秒 | 3秒 |
| grow の1段階のタッチ | 2回 | 3回 | 4回 |
| order でまちがえたら | そのまま | そのまま | 最初から |
| 自動ヒントまで | 6秒 | 10秒 | 15秒 |

遊びの中に `seconds`・`times`・`stay` などを書くと、そちらが使われます。

### 自動ヒント

遊んでいる間、しばらく何も進まないと、次にさわるもの（まだ見つけていない場所、次の順番の絵など）が光ってゆれます。遊びの中に `"hintAfter": 秒` を書くと時間を変えられ、`0` で止められます。

### ひかえめモード

最初の画面の「ひかえめモード」をオンにすると、光の点滅や粒が少なくなり、回る・ゆれる動きがゆっくり小さくなります（ふわふわ・すやすや も小さく、環境音も小さくなります）。スマホの「視差効果を減らす（動きを減らす）」がオンなら最初からオン、一度選ぶとそのスマホで覚えます。`book.json` に `"calm": true` と書くと、最初からオンになります。

## 4. そのほかの設定

| 項目 | 意味 |
|---|---|
| `name` | 画面左上のページ名 |
| `hint` | 画面上に出し続けるヒント。書かないと遊びに合わせて自動で出ます |
| `progress` | 右上の進み具合。`{ "label": "みつけた", "total": 3 }`。`"cast": true` にすると登場人物の色の丸になる。`null` で非表示 |
| `skyFireworks` | `true` にすると、空をタッチした場所に花火が上がる |
| `twinkle` | `false` にすると、ページの小さなキラキラを止める |
| `weather` | 天気・季節。ずっと ふる／ただよう：`snow`（雪）・`rain`（雨）・`petals`（花びら）・`leaves`（落ち葉）・`fireflies`（ほたる）・`bubbles`（あわ）・`stars`（星がまたたく） |
| `ambience` | 環境音。ページを開いている間、小さく流れる（読み上げとセリフの間は もっと小さく）：`waves`（波）・`wind`（風）・`rain`（雨）・`stream`（小川）・`insects`（虫の声）・`birds`（小鳥）・`fire`（たき火）。効果音オフで止まる |
| `dark` | ページを最初から暗くする（0〜0.6）。上の「明かり」 |
| `background` | 背景のひな形（`field`・`night`・`room`・`forest`・`sea`・`snow`）。[03 絵を用意する](03_絵を用意する.md) の「背景のひな形」 |

ずっと少しだけ動いている絵（ふわふわ・すやすや・ゆらゆら・飛び回る）は `pieces` に `"idle"`、ずっと光る絵は `"glow": true` を書きます（[03 絵を用意する](03_絵を用意する.md) の「page.json に並べる」）。

## 5. もっと特別なしかけ

「3かい ノックすると ドアが あく」「ふたつを くっつけると べつの ものに なる」のような、そのページだけの特別な動きは、ページのフォルダに `script.js` を置いて作ります。→ [90 開発者向け](90_開発者向け.md)
