# 越前市ぷらぷらぼ AR えほんキット（pulapulabo-ehon-kit）

紙に印刷した絵本のページをスマホのカメラで映すと、絵が飛び出す絵本のように立ち上がり、さわって遊べる **Web AR 絵本** を作るキットです。Claude に作ってもらう・絵だけ自分で描く・自分のパソコンで ぜんぶ作る、の3つの作りかたができます。
読む人はアプリのインストールがいりません。スマホのブラウザで動きます。

**▶ 見本を見る（デモ）： https://nknhb966.github.io/pulapulabo-ehon-kit/**

越前市ぷらぷらぼ（市民活動団体）が作っています。

## どんな絵本ができるか

- ページを映すと、どのページかを自動で見分けて、そのページの絵が立ち上がる（印刷した紙の絵は見えたまま）
- 「おはなし」→「あそぶ」の2段階。まず読んでから、さわって遊ぶ
- さわると動く・音が鳴る・オノマトペの文字が出る・登場人物がしゃべる（まばたきや口パクもする）
- 雪や花びらがふる、虫の声や波の音が流れる、夜になって窓に明かりがつく など、場面の空気も出せる
- 遊び：さがす・ぜんぶ タッチ・なんども タッチ・じゅんばんに タッチ・えらぶ（クイズ）・でてきたら タッチ（ほたるを つかまえる・金魚すくい など）・おちてくる ものを キャッチ・そだてる・きせかえ・こする・はこぶ・まねっこ・ペアさがし・ながおし・なぞって つなぐ
- ページをまたぐ しかけ：おだんごを もっていくと ふくろうが ほたるを つかまえる あみと こうかんしてくれる（なくても 手で つかまえられる）・つかまえた数が つぎの ページに出る・なかまが ついてくる・ぜんぶ あそぶと 大きな お祝い など
- 絵を 最大5列に 立てて（同じ列の中でも 少し前後させて）、AR で 奥行きが出る
- 読む子の年れい（3・5・7さい）に合わせて、遊びの時間や回数が自動で決まる。しばらく進まないとヒントが出る
- クリアすると登場人物が笑顔になり、ドアが開く・光の道・流れ星・にじ・花火のフィナーレなどの演出が出る。クリアの前と後でセリフも変わる
- 読み上げ（読んでいる行が光る）、効果音、カメラなしで見られるプレビュー（Claude で作ると、チャットの中で すぐ さわれる）
- 印刷用 PDF を自動で作成。表紙と奥付には、絵本を開く QR コードが入る。カメラで表紙を映すと「ページを めくってね」と 1ページを案内
- ページをクリアすると ごほうびスタンプ、最後は「おしまい」ボタンで おしまいの画面。英語・ポルトガル語でも読める
- **ぬりえ：** タブレットで 絵に いろを ぬると（タップで ぬれて はみ出さない）、その いろの まま AR の 絵が 立ちあがって 動く。ワークショップにも（[10 ぬりえ](guide/10_ぬりえ.md)）

## 作りかたは3つ

| | ① Claude で作る | ② Claude で作って、絵を自分で描く | ③ ぜんぶ自分で作る |
|---|---|---|---|
| こんな人に | いちばん かんたん。絵も しかけも まかせたい | 絵は自分の絵にしたい。しかけは まかせたい | 自分のパソコンで、ぜんぶ自分で作りたい |
| 使うもの | Claude | Claude ＋ お絵かきアプリ（iPad などでも OK） | パソコン（Node.js・VS Code）＋ お絵かきアプリ など |
| 説明 | このページの「① Claude で作る」 | このページの「②」と [09 自分の絵に描きかえる](guide/09_自分の絵に描きかえる.md) | このページの「③」と [01 はじめかた](guide/01_はじめかた.md) |

どの作りかたでも、使うキットは同じ1つの ZIP です。できあがりも同じ形（GitHub に上げる ZIP と、印刷用 PDF）なので、とちゅうで作りかたを変えることもできます。

## キットをダウンロードする

**[⬇ pulapulabo-ehon-maker.zip をダウンロード](../../raw/main/pulapulabo-ehon-maker.zip)**（約 5 MB）

うまくダウンロードできないときは、[pulapulabo-ehon-maker.zip のページ](pulapulabo-ehon-maker.zip) を開いて、右上のダウンロードボタン（↓）を押します。

**ChatGPT で作るとき：** [⬇ pulapulabo-ehon-maker-chatgpt.zip（ChatGPT 用・道具入り）](../../raw/main/pulapulabo-ehon-maker-chatgpt.zip)（約 23 MB）を使います（下の「ChatGPT で作るとき」）。

## ① Claude で作る

アプリなどをインストールする必要はありません。

### 1. Claude に頼む

Claude の新しいチャットに **pulapulabo-ehon-maker.zip をそのまま添付**します（展開しなくて OK）。決めかたは2つです。

（Claude で メモリー〈過去の チャットの 参照〉を オンに していても、キットの 指示で 前に 作った 絵本の 内容は 引きつぎません。もし まざったら「前の 絵本の 内容は 使わないで」と 送ります）

**A. 質問に こたえて 決める（おすすめ）**

- **何も書かずに送る**（または「AR えほんを 作りたい」とだけ書く）と、Claude が「どうやって 決めますか？」と聞いてきます。「質問に こたえて 決める」を選びます
- まず **題名と コンセプト**（どんな お話にしたいか、ひとことで）を聞かれます。思いつかないときは「案を出して」と送ります。ここから先の おすすめは、すべて コンセプトに そって 出てきます
- そのあと、前の答えに合わせた おすすめの選択肢つきで、**3つずつ** 質問が出てきます。えらぶか、自分の言葉で書いて答えます（◆ は 1つだけ、☑ は チェックボックスで いくつでも えらべます）

  | 回 | 聞かれること |
  |---|---|
  | 1 | ◆ ページ数・◆ 主人公・◆ お話の流れ |
  | 2 | ☑ なかまの登場人物・◆ 読む子の年れい・◆ さいごの場面 |
  | 3 | ☑ 使いたい遊び・☑ ページをまたぐ しかけ・☑ クリアしたときの演出 |
  | 4 | ◆ 絵の雰囲気・☑ 場面の空気（雪・ほたる・波の音 など）・☑ 主人公の動き |
  | 5 | ☑ 使いたい部品・◆ 絵の作りかた・◆ ことば（英語・ポルトガル語） |
  | 6 | 作者名と GitHub のアカウント名（**かならず聞かれます**。まだなら「あとで」で OK） |

- ☑ の質問では、お話に合う候補が おすすめ順に 4つまで出ます。ほかの候補も 一覧で見せてくれるので、えらびたいものは「その他」に書きます
- 毎回、4つめに「つぎの 質問へ」「あとは おすすめで 作りはじめる」が出ます。とちゅうで「設定おわり」「あとは おすすめ」と書いて送っても、作者名と GitHub のアカウント名を聞かれたあと、そこから作りはじめます
- 題名と コンセプトを 最初から書いて送っても OK です（例：「題名：ほしの さんぽ。コンセプト：ねこが 夜空を さんぽして、星の ともだちを つくる」）。その続きから質問が来ます

**B. 自分で 書く**

次のように書いて送ります。〇〇は、決まっていることだけ書けば大丈夫です（空いているところは、Claude が聞くか おすすめで決めます）。

```
このファイルを参考に、次のAR絵本を作成してください。
・題名：〇〇
・コンセプト：〇〇（どんな お話にしたいか、ひとことで。例：ねこが 夜空を さんぽして、星の ともだちを つくる）
・ページ数：〇〇
・登場人物：〇〇（名前、どんな生きものか、性格、色）
・お話：〇〇（1ページめ…、2ページめ…、さいごは…）
・遊び：〇〇（さがす／ぜんぶ タッチ／なんども タッチ／みんなで おす／じゅんばんに タッチ／えらぶ／でてきたら タッチ／おちてくる ものを キャッチ／そだてる／きせかえ／こする／はこぶ／まねっこ／ペアさがし／ながおし／なぞって つなぐ など）
・クリアしたとき：〇〇（ドアが ひらく／みちが ひかる／ながれぼし／かみふぶき／にじ／さいごは はなびの フィナーレ など）
・読む子の年れい：〇〇さいくらい（3・5・7）
・使いたい部品：〇〇（「使える部品」から。なければ書かなくて OK）
・絵の雰囲気：〇〇（色合い、昼・夜、季節。雪が ふる・虫の声 なども OK）
・絵の作りかた：Claude に まかせる／あとで 自分の絵に 描きかえる（お絵かきアプリ・PNG）／あとで 自分の絵に 描きかえる（ベクターアプリ・SVG）
・作者名：〇〇（まだなら「あとで」）
・GitHub のアカウント名：〇〇（まだなら「あとで」）
```

コンセプトに そって、登場人物・お話・遊び・クリアしたときなどを 作ります（書いていないところも、コンセプトに合わせて おすすめで決めます）。

- どちらの決めかたでも、作者名と GitHub のアカウント名（表紙と奥付の QR コードに入ります。まだなら「あとで」で OK）と、英語・ポルトガル語でも読めるようにするかを聞かれます（ことばを答えないときは、日本語・英語・ポルトガル語の3つで作ります）
- Claude がキットの中のプログラムを動かして作ります。ファイルを作って返せる Claude を使ってください（動作を確かめたのは Claude のアプリです）

### 2. 受け取る

できあがると、Claude のチャットの中に **「＜題名＞ — カメラなしプレビュー」の カード（アーティファクト）** が出ます。開くと、ダウンロードしなくても さわって 動きを 確かめられます（カードを出せない Claude では、`<名前>_preview.html` を ダウンロードして開きます）。あわせて、次のファイルが届きます。

| ファイル | すること |
|---|---|
| `<名前>_github.zip` | GitHub に上げる（下の 3.） |
| `<名前>_source.zip` | **保存しておく。** あとで直すときに使います |
| `<名前>_A4.pdf` | 印刷する |
| `<名前>_preview.html` | カメラなしの プレビュー（1つのファイル。開くだけで 動きます） |
| `<名前>_png.zip`・`<名前>_svg.zip` | 「あとで 自分の絵に 描きかえる」にしたときだけ。描くときの下絵（下の「②」） |

### 3. 公開する

1. GitHub で新しいリポジトリを作ります（名前は Claude が教えてくれた `<名前>`、**Public**）
2. `<名前>_github.zip` を展開し、中身（`index.html`・`preview.html`・`ehon`・`print`・`THIRD_PARTY_LICENSES.txt`）を**全部選んで**、リポジトリの「uploading an existing file」にドラッグ → **Commit changes**
3. **Settings → Pages** で、Branch を `main`・`/ (root)` にして **Save**
4. 数分後、`https://（アカウント名）.github.io/<名前>/` をスマホで開きます
5. 読み上げを確かめます：`https://（アカウント名）.github.io/<名前>/preview.html#yomi` を開くと、すべての文章とセリフを ▶ で聞けます。読みかたが ちがう言葉があれば、読み上げ原稿（read）を直します（Claude で作ったときは Claude に伝えます）

くわしくは [06 公開と印刷](guide/06_公開と印刷.md) にあります。

### 4. 印刷して遊ぶ

PDF を **A4 横・「実際のサイズ」** で印刷し、スマホで公開ページを開いて「カメラで はじめる」→ 印刷したページを映します。

### 直したいとき

- 同じチャットなら、「2ページめの ねこを もっと大きく」のように頼むだけです
- 別のチャットでは、`pulapulabo-ehon-maker.zip` と `<名前>_source.zip` を一緒に添付して「この絵本の〇〇を直してください」と頼みます
- 絵やページの文章を直したときは、印刷し直してください

### ChatGPT で作るとき

ChatGPT（ファイルを読んで プログラムを 動かせる モデル）でも 作れます。

1. [ChatGPT 用（道具入り）の ZIP](../../raw/main/pulapulabo-ehon-maker-chatgpt.zip) を ダウンロードします（ふつうの ZIP では、ChatGPT の 中で 道具を 入れられないことが あります）
2. **前に 作った 絵本が まざらないように、一時チャットで はじめます。** ChatGPT は メモリー（記憶）と チャット履歴の 参照で 前の チャットを おぼえていて、前の 絵本の 題名や 登場人物を 引きついでしまうことが あります。新しい チャットの 画面で「一時チャット」を えらび、さいしょの メッセージの 前に **「パーソナライズなし」** に します（メモリーを 使わない）。一時チャットを 使わないときは、設定 → パーソナライズ で「メモリ」と「チャット履歴を参照する」を オフに します
3. ChatGPT に その ZIP を 添付して、次のように 送ります

```
この ZIP の README.md を さいごまで 読んで、その指示どおりに AR えほんを 作ってください。前の チャットや メモリーの 内容は 使わないでください。
```

4. あとは 上と 同じです。ChatGPT では チャットの 中に プレビューの カードは 出ないので、届いた `<名前>_preview.html` を ダウンロードして 開きます
5. 作るのに 数分 かかります。とちゅうで 止まったら「つづけて」と 送ります
6. 一時チャットは あとから 見られなく なります。できた ZIP・PDF は かならず ダウンロードして おきます（直すときは `<名前>_source.zip` を 添付して たのみます）

## ② Claude で作って、絵を自分で描く

Claude に作ってもらった絵本の絵を、自分で描いた絵に入れかえます。動き・しかけ・文章は そのままです。パソコンがなくても（iPad などで描いて、Claude に入れかえてもらえば）できます。

| 描くアプリ | 絵のファイル | 下絵セット |
|---|---|---|
| お絵かきアプリ（Procreate・CLIP STUDIO PAINT・アイビスペイント など） | PNG（2400×1800） | `<名前>_png.zip` |
| ベクターアプリ（Illustrator・Inkscape・Affinity Designer・Figma など） | SVG（1600×1200） | `<名前>_svg.zip` |

| | すること | どこで |
|---|---|---|
| 1 | 「① Claude で作る」で作る。「絵の作りかた」は **「あとで 自分の絵に 描きかえる（PNG か SVG）」** | Claude |
| 2 | プレビューで遊んで、動き・しかけ・絵の分けかたを **描く前に決めきる**（直しは Claude に） | Claude |
| 3 | 下絵セットをもらう。ページごとに、すべての絵と、重ねた下絵（`_下絵.png`）、奥行きの列と文章の箱のガイド（`_ガイド`）、どの絵が何かの一覧が入っている | Claude |
| 4 | 下絵の上に描く。1つの絵 = 1つのレイヤー（ファイル）。キャンバスの大きさのまま・まわりは透明・同じ名前で書き出す | 描くアプリ |
| 5 | 描いた絵を フォルダ分けのまま ZIP にして添付し、「この絵に差しかえてください」 | Claude |
| 6 | 新しい `<名前>_github.zip` で公開し直し、**印刷し直す** | GitHub・プリンター |

- 1ページだけ・主人公だけ、のように少しずつ入れかえても大丈夫です（描いていない絵は Claude の絵のまま）
- 新しい絵の登場人物は、表情の絵（笑顔・まばたき・口パク）を自分で描くと使われます（描かなくても動きます）

### 自分のパソコンで 下絵を作る・入れかえるとき

Claude に頼まずに、自分のパソコンで `npm run png`（お絵かきアプリ用の下絵）・`npm run svg`（ベクターアプリ用の下絵）・`npm run put-png -- 描いた絵のフォルダ`（入れかえる）を使うこともできます。そのときは先に、下の「③ の 1. 準備する（最初に1回）」と同じことをします。

1. [Node.js](https://nodejs.org/)（20 以上）と [VS Code](https://code.visualstudio.com/) を入れ、`pulapulabo-ehon-maker.zip` を展開して VS Code で開き、ターミナルで `npm install`
2. Claude からもらった `<名前>_source.zip` を `books/` の中に展開し（`books/<名前>/book.json` ができる）、`npm run use -- <名前>`
3. `npm run png`（または `npm run svg`）→ 描く → `npm run put-png -- 描いた絵のフォルダ` → `npm run build` → `npm run pack`

くわしくは **[09 自分の絵に描きかえる](guide/09_自分の絵に描きかえる.md)** にあります。

## ③ ぜんぶ自分で作る（自分のパソコン）

Claude を使わずに、キットを自分のパソコンで動かして作ります。プログラムを書いたことがなくても、説明書を見ながら作れます。

### 1. 準備する（最初に1回）

1. [Node.js](https://nodejs.org/)（20 以上）と、ターミナル付きのエディタ（[VS Code](https://code.visualstudio.com/) など）を入れます
2. `pulapulabo-ehon-maker.zip` を展開し、そのフォルダ（`package.json` がある場所）を VS Code で開きます
3. ターミナルで `npm install` を打ちます（道具が入ります。1分ほど）
4. `npm run build` を打ち、できた `publish/sample-svg/preview.html` をダブルクリックして、見本が見られたら準備完了です

くわしくは [01 はじめかた](guide/01_はじめかた.md) にあります。

### 2. 作る

- `npm run new-book -- my-book` で自分の絵本のフォルダを作り（見本がコピーされます）、説明書を見ながら書きかえていきます
- 絵は SVG（Illustrator・Inkscape など）でも、お絵かきアプリの PNG でもかまいません。`npm run png`・`npm run svg` で 見本の絵を下絵にでき、奥行きの5列と文章の箱が分かる ガイド（`_ガイド`）も入ります（[03 絵を用意する](guide/03_絵を用意する.md)・[09](guide/09_自分の絵に描きかえる.md)）
- 設定（book.json・page.json）は、**Excel の表** でも書けます。`npm run excel` で表（`out/<名前>_表.xlsx`）ができ、動き・音・遊び などを ▼ で えらんで書けます。保存して `npm run excel-in` をすると json になります（Excel・LibreOffice・Google スプレッドシート。[02 新しい絵本を作る](guide/02_新しい絵本を作る.md)）
- `npm run pack` で、Claude で作ったときと同じ `<名前>_github.zip`・`<名前>_source.zip` ができます。公開と印刷は、上の「① の 3. 公開する」「4. 印刷して遊ぶ」と同じです
- Claude で作った絵本をパソコンで直したり、パソコンで作った絵本の続きを Claude に頼んだりもできます（[01 はじめかた の「8. Claude と行き来する」](guide/01_はじめかた.md#8-claude-と行き来する)）

## 使える部品

頼むときに「使いたい部品」に名前を書くと、その部品を使って作ります。くわしくは [08 部品カタログ](guide/08_部品カタログ.md) にあります。

**遊び（1ページに1つ）**：さがす・ぜんぶ タッチ・なんども タッチ・みんなで おす・じゅんばんに タッチ・えらぶ（クイズ）・でてきたら タッチ（出かた：ぴょこっ・泳ぐ・飛ぶ。かくれる場所・入れ物に たまる・道具と手）・おちてくる ものを キャッチ・そだてる・きせかえ・こする・はこぶ・まねっこ・ペアさがし・ながおし・なぞって つなぐ

**遊びやすさ**：年れいの設定（3・5・7さい）・自動ヒント・ひかえめモード

**さわったとき**：動き（はねる・回る・飛ぶ・ドアが外へ開いて 戸口から外の景色が見える・とりは 向いている方へ飛ぶ など）・効果音・オノマトペ・セリフ・絵の切りかえ・かくれた絵が出る・キラキラや花火などの演出・気持ちのマーク（！ ♪ ハート など）・道を歩く・明かりがつく・箱の中から出てくる・間（ま）をあけて つづけて動く（チクタク……ポッポー）・クリアの前と後で変わる反応・セリフや文字が重なったら 最後にさわった物が手前

**クリアしたとき**：みんなが笑顔になる・物が動く・光の道・歩いて帰る・夜になって明かりがつく・気分に合わせた おしまい（流れ星・紙ふぶき・花・あわ・にじ）・花火・大フィナーレ

**ページ全体**：天気・季節（雪・雨・花びら・落ち葉・ほたる・あわ・星）・環境音（波・風・雨・小川・虫の声・小鳥・たき火）・夜のページ・空の花火・ページのキラキラ・読み上げ・読みに合わせて動く

**登場人物と絵**：まばたき・口パク・表情の絵が自動でできる（顔のパーツ）・ふわふわ／すやすや／ゆらゆら動く・飛び回る・ずっと光る・背景のひな形（のはら・よる・おへや・もり・うみべ・ゆき）

**ぬりえ**：タブレットで タップして ぬる（登場人物と 小物だけ／はいけいも）・ぬった いろで AR が 動く・その タブレットに 自動で 保存

**本の形とお話**：表紙と奥付（QR コード入り。カメラで表紙を映すと 1ページを案内）・ごほうびスタンプ・おしまいの画面・おとなの かたへ・読んでいる行が光る・ふりがな・大きい文字・もちもの（かぎで ドアが開く・わたす と なくなる）・えらんだ方で変わる・かぞえた数が つづく・なかまが ついてくる・きせかえが つづく・クリアした ページや スタンプの数で 変わる・奥行き（最大5列）・英語とポルトガル語（AR に その言葉の文章を重ねる「もじ」ボタン）

## キットの中身

`pulapulabo-ehon-maker.zip` を展開すると、次のフォルダとファイルが入っています。Claude に作ってもらうときも、自分で作るときも、書きかえるのは `books/<名前>/` の中だけです（受け取る `<名前>_source.zip` の中身も このフォルダです）。

```
pulapulabo-ehon-maker/
  README.md            Claude（AI）への作業の指示書（Claude が最初に読む）
  つかいかた.md         人向けの使いかた（このページの「作りかた」と同じ内容）
  CLAUDE.md            Claude への案内（README.md を読む）
  LICENSE              ライセンス（MIT）
  package.json         コマンド（npm run build など）と、使う道具の一覧
  package-lock.json    道具の版を固定するファイル
  ar-book.config.json  いま作っている絵本の名前（npm run build で作る絵本）

  books/               絵本の元データ（1冊 = 1フォルダ）
    sample-svg/        見本「ねこと おつきさま」（新しい絵本は、これをコピーして作る）
      book.json        題名・登場人物・声・全体の設定
      read.json        セリフの読み上げ方（ひらがなの文 → 漢字まじりの読み上げ）
      cover.svg        表紙の絵
      cast/            はじめる画面に出す登場人物の絵
      items/           もちものの絵
      lang/            英語・ポルトガル語の訳
      pages/
        p1/            1ページめ（p2〜p4 も同じ形）
          page.json    文章・飛び出す絵の並び・さわったときの反応・遊び
          script.js    そのページだけの動き
          layers/      このページの絵（.svg でも .png でも）
            _background.svg  紙に残る背景
            cat.svg          飛び出す絵（1つずつ別のファイル）
            moon@awake.svg   さわると切りかわる絵（moon.svg の別の姿）

  guide/               説明書（01〜10・90。このページの「説明書」と同じもの）

  system/              しくみ（ふつうは変えない）
    engine/            絵本を動かすプログラム（スマホのブラウザで動く部分）
    tools/             作る道具（build・check・new-book・add-page・pack・preview・png・svg・put-png・excel など）
    backgrounds/       背景のひな形（のはら・よる・おへや・もり・うみべ・ゆき）
    vendor/mind-ar/    画像認識のライブラリ MindAR と、認識データを作る部品
    fonts/             絵本の文字（Zen Maru Gothic）
```

自分のパソコンで作ると、次のフォルダができます（ZIP には入っていません）。

| フォルダ | 中身 |
|---|---|
| `node_modules/` | `npm install` で入る道具 |
| `publish/<名前>/` | `npm run build` のできあがり。**この中身が GitHub に上げるもの**（`<名前>_github.zip` と同じ） |
| `out/` | `npm run pack`・`npm run png`・`npm run excel` などの出力（`<名前>_github.zip`・`<名前>_source.zip`・`<名前>_preview.html`・`<名前>_png/`・`<名前>_表.xlsx`） |

## 見本の絵本「ねこと おつきさま」（4ページ）

| ページ | 場面 | 遊び |
|---|---|---|
| 1 | やねの うえ | かくれている ものを さがす |
| 2 | おつきさまの おちゃかい | 8秒の うちに みんなを タッチ（おだんごを もらえる） |
| 3 | くもを どかそう | みんなを タッチしてから、くもを なんども タッチ |
| 4 | ほたるの みち | 草むらから 出てくる ほたるを つかまえて、びんに あつめる（おだんごが あると、ふくろうが あみと こうかん） |

どのページも、絵を 4〜5列に 立てて（同じ列の中でも 少し前後させて）、AR で 奥行きが 出るように しています。

[デモ](https://nknhb966.github.io/pulapulabo-ehon-kit/) で、カメラなしでも遊べます。
