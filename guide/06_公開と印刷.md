# 06 公開と印刷

## 1. GitHub に上げるもの

絵本のできあがりは、`npm run build` でできる `publish/<絵本名>/` フォルダです（`<絵本名>_github.zip` の中身と同じ）。**GitHub に上げるのは、この中身だけ**です。

| ファイル | 上げる？ | 中身 |
|---|---|---|
| `index.html` | **必ず** | AR 絵本の本体（カメラで映す） |
| `ehon/` | **必ず** | プログラム・絵・文字・認識データ。`index.html` と `preview.html` が使います。**これがないと、まっ白な画面になります** |
| `preview.html` | おすすめ | カメラなしで遊べる版（`…/preview.html` で開ける） |
| `print/` | おすすめ | 印刷用の PDF と画像。読む人が自分で印刷できます（`…/print/<絵本名>_A4.pdf`） |
| `THIRD_PARTY_LICENSES.txt` | おすすめ | 使っているライブラリとフォントのライセンス表示（画面の「ライセンス表示」にも入っています） |

**上げないもの：** `books/`・`system/`・`node_modules/`・`guide/`・`package.json` など、`publish/` 以外のすべて。絵本を動かすのには使わないうえ、上げると絵の元のデータまで だれでも見られるようになります。

> `publish/` の中は、`npm run build` のたびに作り直されます。**手で直さず、`books/` を直して作り直してください。**

### ehon フォルダの中身

| ファイル | 中身 |
|---|---|
| `book.js` | 絵本の設定・文章・しかけ（読める形。元は `books/<絵本名>/`） |
| `engine.js` | 絵本を動かすプログラム（読める形。元は `system/engine/`） |
| `pictures.js` | 絵と文字のデータ |
| `targets.mind` | カメラがページを見分けるためのデータ（`index.html` だけが使う） |
| `three.js`・`mindar.js` | 使っているライブラリ（three.js と MindAR。`mindar.js` は `index.html` だけが使う） |
| `style.css`・`licenses.js` | 見た目と、ライセンス表示の文 |

ライブラリも自分の GitHub に一緒に置くので、外のサイトに頼らずに動きます。ファイル名のうしろに版の印（`?v=…`）を付けて読みこむので、上げ直したあとに古いファイルと新しいファイルが混ざることもありません。

> `npm run pack` をすると、`out/<絵本名>_github.zip`（上の5つをまとめたもの）と `out/<絵本名>_source.zip`（`books/<絵本名>/` の元データ。あとで直すときに使う）ができます。

## 2. はじめて公開する

1冊の絵本につき、GitHub の **リポジトリ（置き場所）を1つ** 作ります。

### ① GitHub のアカウントを作る（1回だけ）

https://github.com で **Sign up** から作ります（無料）。アカウント名が公開 URL に入ります。

### ② リポジトリを作る

1. GitHub の右上の **＋** → **New repository**
2. **Repository name** に、絵本のフォルダ名（例：`my-book`）を入れます
3. **Public** を選びます（無料のプランでは、Public でないと公開ページが作れません）
4. ほかはそのままで、**Create repository** を押します

### ③ ファイルを上げる

1. できたリポジトリのページにある **uploading an existing file** という青い文字を押します
   （README を作った場合は **Add file → Upload files**）
2. `my-book_github.zip` を展開したフォルダ（または `publish/my-book/`）を開き、**中身をぜんぶ選んで**（Windows：`Ctrl`+`A`、Mac：`⌘`+`A`）、ブラウザの点線の枠にドラッグ＆ドロップします
   - `my-book` フォルダそのものではなく、**中身**をドラッグします（フォルダごと入れると URL がずれます）
3. 読みこみが終わったら、いちばん下の緑の **Commit changes** を押します
4. リポジトリのファイル一覧に、`ehon`・`print`・`THIRD_PARTY_LICENSES.txt`・`index.html`・`preview.html` が並んでいれば OK です（`ehon` と `print` はフォルダのまま上がります）

### ④ 公開ページを作る（1回だけ）

1. リポジトリの上の **Settings** → 左の **Pages**
2. **Build and deployment** の **Source** を「Deploy from a branch」にします
3. **Branch** を `main`、その横を `/ (root)` にして **Save**
4. 数分たってから Pages の画面を開き直すと、上に公開 URL が出ます

```
https://あなたのアカウント名.github.io/my-book/              ← AR 絵本
https://あなたのアカウント名.github.io/my-book/preview.html  ← カメラなし
https://あなたのアカウント名.github.io/my-book/print/my-book_A4.pdf  ← 印刷用
```

## 3. 直したあとに公開し直す

1. 作り直したもの（新しい `my-book_github.zip` を展開したフォルダ、または `publish/my-book/`）を用意します
2. リポジトリのページで **Add file → Upload files** を押し、③と同じように中身をドラッグ → **Commit changes**（同じ名前のファイルは上書きされます）
3. 数分で公開ページが新しくなります。スマホは再読み込みしてください

> ページを減らしたときは、GitHub に古い `print/page5.png` などが残ります。気になるときは、GitHub でそのファイルを開き、右上の「…」→ Delete file で消します。

## 4. ファイルが 25 MB をこえたとき

ブラウザから上げられるのは 1ファイル 25 MB までです。ページがとても多いと `ehon/` の中のファイル（`pictures.js` など）がこえることがあり、そのときは作るときに ⚠️ が出ます。そのときは **GitHub Desktop**（https://desktop.github.com）を使います（1ファイル 100 MB まで）。

1. GitHub Desktop を入れて、GitHub のアカウントでサインイン
2. **File → Add local repository** で、`my-book_github.zip` を展開したフォルダ（または `publish/my-book`）を選び、「create a repository」を押して作成
3. **Publish repository** を押します（「Keep this code private」のチェックは外す）
4. GitHub で ④ の公開設定をします
5. 直したあとは、新しい中身をそのフォルダに上書きしてから、GitHub Desktop で **Commit to main** → **Push origin**

## 4-2. GitHub 以外に 置くとき

学校・会社の サーバーや、ほかの 公開サービスにも 置けます。

1. `book.json` の `"url"` に、絵本を開く URL を 書きます（`https://` で 始まり、最後は `/`。例：`"url": "https://example.com/ehon/my-book/"`）。`"github"` は `""` に します
2. `npm run pack` をすると、`out/<絵本名>_web.zip` が できます（GitHub 用の `_github.zip` の かわり。中身は 同じ）。表紙と 奥付の QR コードは この URL に なります
3. `<絵本名>_web.zip` を 展開して、中の ファイルと フォルダ（index.html・preview.html・ehon・print・THIRD_PARTY_LICENSES.txt）を、その URL の フォルダに そのまま 置きます（中の ならびは 変えない）
4. スマホで その URL を 開きます

- **https で 開ける 場所に 置いてください。** カメラは https の ページでしか 動きません（http だと「カメラなしで みる」だけ）
- ファイルを 置くだけで 動きます（サーバーで プログラムを 動かす ひつようは ありません）
- 「おとなの かたへ」には、GitHub の ページの かわりに この URL が「この絵本のページ」として 出ます

## 5. スマホで試す

- AR のカメラは **https のページ**でしか動きません。GitHub Pages は https なので、そのまま使えます（ほかの場所も https に してください）
- iPhone は Safari、Android は Chrome がおすすめです
- 公開 URL を知っている人は、だれでも見られます
- 公開 URL のうしろに `preview.html#yomi` を付けて開くと「よみあげ チェック」になります。すべての文章とセリフを、そのスマホの声で ▶ で聞いて確かめられます（[04 文章と読み上げ](04_文章と読み上げ.md) の「読みまちがいを防ぐ」）

## 6. 印刷する

- `<絵本名>_A4.pdf`（できあがりの `print/` の中にもあります）を **A4 横・実際のサイズ（拡大縮小なし）** で印刷します。ページの紙は、絵だけが A4 いっぱいに 入っています（まわりに 5mm の 白い ふち）
- つやのない紙の方が、光が反射しにくく、よく見分けられます
- **絵や文章を変えたら、必ず印刷し直してください。** カメラは、作ったときのページの絵と見比べてページを見分けています
- ページをとじて本にするときは、平らに開くようにすると見分けやすくなります

### 表紙と奥付・QR コード

`book.json` の `"print"` に `"cover": true`（表紙）・`"colophon": true`（奥付：最後の紙）を書くと、PDF の最初と最後に付きます（`print/cover.png`・`colophon.png` もできます）。

- 表紙：題名（絵の上、絵の外に1か所）・表紙の絵・作者名・QR コード
- **表紙の絵は「お話の場面」ではなく「お話の看板」です。** 1ページぶんの場面を描くのではなく、お話を代表するものを パッと見せて、どんなお話か 思いうかぶ絵にします。入れるのは次の3つだけです
  1. **主人公たちを大きく**：絵の高さの半分くらい。横に ならべて（少し重なってもよい）、正面を向いた笑顔（`@happy` など）
  2. **お話らしい背景を1つ**：夜空と星・海・森・雪 など。空や色の面に、細かい模様（星・波・葉）を散らす
  3. **お話のいちばんの特徴を大きく**：花火・お月さま・雪だるま など 1〜3こ。主人公の うしろか上に
- 描かないもの：ページの背景（`_background`）や、家具・小物・道・地面の こまかい物（ページの場面に見えてしまう）。**文字**（題名は キットが絵の外に入れる）
- **どのページとも ちがう絵にします。** ページと同じ絵だと、印刷した表紙を カメラが そのページと まちがえて、そのページの AR が出てしまうためです。主人公を ページより ずっと大きく描くと、ちがう絵になります
  - `books/<絵本の名前>/cover.svg`（または `cover.png`）に、横 1600 × たて 936 で描きます。主人公の絵は ページの絵（`<g>…</g>`）を コピーして、大きさと ならびを変えて使います
  - `cover.svg` がないときは、キットが 登場人物（`cast/` の絵）を 大きく ならべた表紙を 自動で作ります
  - 作るときに、表紙が どれかのページに にていたら「⚠️ 表紙の絵が ○ページの絵に にています」と出ます。そのときは 表紙の絵を 描きなおします
- **カメラで表紙を映すと、表紙の上に「ページを めくって、この ページを うつしてね」の札が出ます。** 札には 1ページの小さな絵、紙の右はしには めくる向きの矢印が ゆっくり動きます。表紙を 映している あいだ、5秒ごとに「キラリン」と鳴り、その すぐあとに 札の 言葉を 声で 言います（セリフが オンのとき。「よむ」を押しても言います）。さわって遊ぶものは ありません（表紙を映しても 何も出ないと思われないための案内です）。こうかおんが オンなら、画面の上に「キラリンが きこえないときは［よみこみなおす］」が 出ます（音が 出ているかを たしかめるため）。「ことば」で もじを かえると 札の 文字が、こえを かえると すぐに キラリンと その 言葉の 声が 出ます
  - キットが自動で作るので、描くものや書くものは ありません。`"cover": true` のときだけです
  - 表紙（絵・題名・作者名・QR コード）を変えたら、表紙も印刷し直します。カメラは 印刷した表紙の絵で 表紙を見分けます
- 奥付：題名・作者・発行日・公開ページの URL と QR コード・読みかた・使ったもの（フォント・AR のしくみ）
- QR コードは、`book.json` の `"github"`（GitHub のアカウント名）から作る公開ページの URL です（`https://<アカウント名>.github.io/<絵本の名前>/`）。**リポジトリの名前を絵本の名前（books/ のフォルダ名）と同じにしてください**。GitHub 以外に 置くときは `"url"` の URL です（上の 4-2）
- QR コードを印刷した紙（表紙・奥付）には「QRコードは株式会社デンソーウェーブの登録商標です。」が 自動で入ります
- `"github"`（または `"url"`）が まだ決まっていないときは QR コードなしでできます。決まったら書いて作り直し、印刷し直します（表紙と奥付だけ印刷し直せば OK。ページの紙はそのまま使えます）

## 7. 認識データについて

作るときに、ページの絵からカメラが見分けるためのデータを作ります。時間がかかるので `.cache/` に保存しておき、**ページの絵が変わっていなければ次からはそれを使います**。しかけ・セリフだけを変えたときは速く終わります（ページの文章は紙に印刷されるので、文章を変えると作り直しになります）。

## 8. うまくいかないとき

### 見るとき

**preview.html を開いても、何も出ない・まっ白**
少し待ってみてください（ファイルが大きいので数秒かかります）。古いブラウザでは動かないことがあります。Chrome・Edge・Safari の新しいものを使ってください。

**カメラが動かない**
- 公開した URL（https のページ）で開いていますか？ `index.html` をファイルのまま開いたときは、カメラが使えません
- カメラの使用を「許可」しましたか？ 断ってしまったときは、ブラウザの設定でこのサイトのカメラを許可してください
- LINE などのアプリの中のブラウザでは動かないことがあります。Safari や Chrome で開いてください

**ページを映しても何も出ない**
- 表紙を映すと「ページを めくって、この ページを うつしてね」の札が出ますか？ 出れば カメラと 公開ページは 動いています（表紙を印刷したとき）
- 印刷したものが、いま作った絵本と同じですか？ 絵や文章を変えたら印刷し直します
- 明るい場所で、ページ全体が画面に入るように映します。近すぎ・ななめすぎると見分けにくくなります
- 光がテカっていないか確かめます
- それでもダメなら、絵に模様や細かいものを足すと見分けやすくなります（[03 絵を用意する](03_絵を用意する.md)）

**絵がずれる・ガタガタする**
スマホを少し離して、ゆっくり動かします。ページが曲がっていると揺れやすくなります。

**声が出ない・音が出ない**
- 表紙を映すと、5秒ごとに「キラリン」と鳴り、つづけて「ページを めくって…」と 声が 出ます（こうかおん・セリフが オンのとき）。聞こえないときは、画面の上の「よみこみなおす」を おします
- iPhone・iPad は、横のマナースイッチが「消音」だと 効果音（キラリン など）が 出ません（声は 出ます。効果音は ふつうの 音の 出かたで 鳴らしています）
- 電話や ほかの アプリの あとで 音が 止まったときは、画面に さわると また 出ます
- 「セリフ」「こうかおん」のボタンがオンになっているか確かめます
- 読み上げの声はスマホに入っている音声を使います。スマホの設定で日本語の読み上げ音声が入っているか確かめてください

**読み方がおかしい**
`page.json` の `read`、セリフは `read.json` に読み上げ用の原稿（漢字まじり）を書きます（[04 文章と読み上げ](04_文章と読み上げ.md)）。

### 公開するとき

**公開 URL を開くと 404（ページが見つかりません）**
- Settings → Pages で、Branch が `main`、`/ (root)` になっていますか？
- 設定してから数分かかります。少し待ってから開き直してください
- 画面に「ehon フォルダが 見つかりません」と出たら、`ehon` フォルダが上がっていません。できあがりの中身をもう一度ぜんぶドラッグしてください
- リポジトリのファイル一覧のいちばん上に `index.html` と `ehon` がありますか？ `my-book` というフォルダの中に入っていたら、フォルダごとドラッグしてしまっています。URL の最後に `my-book/` を足すと開けますが、直すときは中身だけを上げ直してください

**Pages の画面に「Upgrade or make this repository public」と出る**
リポジトリが Private（非公開）です。Settings → General のいちばん下の **Change visibility** で Public にします。

**「Yowza, that's a big file」などと出て上げられない**
25 MB をこえるファイルは、ブラウザからは上げられません。上の「4. ファイルが 25 MB をこえたとき」を見てください。

**公開ページが新しくならない**
Commit してから数分かかります。スマホのブラウザに古いページが残っていることもあるので、再読み込みしてください。
